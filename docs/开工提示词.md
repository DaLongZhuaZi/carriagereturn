## 二、分阶段执行（每阶段：实现 → hvigor test → 真机截图回归 → 提交 main → 文档补录 → 汇报；阻塞停下，不擅自改方案）

- 阶段 1：项目骨架 + 主屏打字闭环。接默认机/默认纸/默认字体/音效包；自绘英文 QWERTY 键盘（容器级 onTouch，弹簧曲线，按下约 0.92 缩放，松开 springMotion，只动 transform/透明度）；纸面 List + LazyForEach + @Reusable；声音在 TouchType.Down 当刻触发（动画 → 播音 → 震动，fire-and-forget；SoundPool 预加载整机音包；震动 15–30ms，usage touch，需 VIBRATE 权限）；行末约 8 字预告铃；首屏标准：打开即美机 + 纸 + 引导，3 秒内敲出第一声。
- 阶段 2：中文输入法双通道。系统输入法 attach（事件订阅必须在 attach 之前；attach/detach 成对；窗口须聚焦）；setPreviewText 预编辑层浅色 + 下划线，只显示、不进文档模型；finishTextPreview 到达必清；insertText 到达先清预编辑串再拆单字约 30–50ms 逐字落字（每字一音一动画）；无预编辑时 deleteLeft 才删正文；双通道切换互斥（先 hideTextInput/detach 再亮自绘键盘，反之亦然）；避让用 OFFSET_WITH_CARET 或 RESIZE_WITH_CARET 保当前行可见。分输入法逐项真机测试（搜狗/讯飞等，每家单列配置与结果：setPreviewText 有无、预编辑显示、光标选区同步、删除语义、回车键行为、键盘高度与避让）。
- 阶段 3：折叠屏三态 + 换装 + 收藏成就 + 文档库 + 导出分享 + 设置。半开约 90° 桌台模式（上半屏纸张、下半屏机械键盘，铰链即分界，任何内容不跨铰链）；三态切换只换布局参数不重建编辑器、不 detach 输入法、文档光标纸张位置全保留；成就按体系文档实现（顺序 1920s → 1950s → 1960s → 1930s；流线时代 = 累计 5000 字 + 用过 2 种纸；电动时代 = 连续 7 天 + 导出分享 3 次；便携时代 = 换过字体与色带 + 半开打字 1 次；计数口径：自然日有落字计一天、成功拉起系统分享面板计、成功切换并落字计、HALF_FOLDED + 横屏 + 角度约 60°–120° 下落字计）；导出：图片离屏截图、PDF Kit 主路径（必须先 insertBlankPage 再 getPage）、分享 uri 必须 fileUri.getUriFromPath 转 file:// URI。
- 阶段 4：专项回归。核心打字体验调研报告 §8.1 的 9 项真机验证逐项过（PDF Kit 全链路、第三方 setPreviewText、updateCursor 坐标空间、SoundPool 重叠行为、折叠角度阈值与折痕 rect 校准、三折叠双角度、PDF 自定义字体、PDF 分享 UTD、长图导出内存上限）；引导两类机制（首次使用引导只显示一次 + 常驻引导每张新纸一行、输入后消失），文案走资源文件占位句、上线前由用户定稿。

## 三、硬约束（违反即返工）

- 完全离线：无联网、无服务器、无遥测；用户文档与按键数据只存本地、不收集不上传。
- ArkTS 显式类型，禁 any/unknown；文案全部走资源文件，渲染器与代码里不写死文案；文档中文、UTF-8。
- 可编辑文本模型：文档按行存数组 + 元数据 JSON，另存纯文本 .txt；绝不学 Rebi 存图片。
- 版权红线：机器全部虚构时代机，不镜像任何真机；prompt 里绝不出现品牌名与型号名；商店素材不出现品牌名；字体按 app/ 内协议原文执行（附 OFL/Apache 文本、不单卖字体文件、改版守保留字）；音效包只进编译产物相关路径，CC BY 两件署名进致谢页。
- 方向：手机/平板/PC 竖屏默认锁定；横屏不做简单适配（将来完全重新设计，不在本批）；折叠屏走三态，不受锁定影响。
- 便携时代在非折叠设备上的等价条件仍待定：不要自编替代规则，现阶段仅折叠屏可达成。
- 键帽全空、字头空白：任何新生成素材不得 baked 文字、Logo、品牌名。
- 汇报要求：每阶段报已核实项、出入项、无法独立验证项；真机数值、截图、单测运行结果以实测为准，不编造；版本号、提交 SHA、文件路径写实。
