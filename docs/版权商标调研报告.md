# 《回车》历史名机收藏：版权与商标风险调研汇报

> 调研员交付（2026-11-03）。**先说定位：本汇报基于公开网络检索，不是法律意见。** 下文分两类标注：****指检索到的公开事实；****指必须由执业律师结合注册库与定稿素材确认的事项。

## 结论先行

**推荐路线：时代风格原创机（B）+ 史实介绍文字（C），不做真名复刻（A），现阶段不启动授权。** 关键结论只有一句：**设计专利全部过期不是通行证，商标与商业外观才是真正的红线**——而同行（Hanx、Printique、Rebi）无一用真名真机，这就是行业共识做法。

**核心判断：没有一个主要品牌是“死干净了可以随便用的”。** 最容易误判的是 Selectric——美国注册确实死了，但这只解决“注册商标”这一层，不解决 IBM 驰名声誉、商业外观与中国注册三层。

## （2）标志性机型：设计专利 vs 商标 / 商业外观

- **设计专利（有期限，已过期）**：美国 15 年（2015 年 5 月 13 日后申请；之前 14 年），不可续；欧盟外观设计最长 25 年；中国外观设计专利 15 年（2021 年修法后，此前 10 年）。Valentine（1969）、Selectric（1961）、Lettera 22（1950，设计师 Marcello Nizzoli）、Lettera 32（1963）的设计专利在主要法域均已过期——**专利不构成障碍**（逐机型专利号未逐一检索，列入律师核查）。
- **商标 / 商业外观（无固定期限，是真红线）**：美国《兰哈姆法》第 43(a) 条下的商业外观保护，只要持续使用且具显著性就可无限续存；中国《反不正当竞争法》第 6 条对“有一定影响的商品装潢”同样保护。**专利过期 ≠ 外观可自由复刻。**
- **机型分级**：
- **Valentine（最高风险）**：Sottsass + Perry King 设计，1969 年推出，1975 年停产；亮红 ABS 楔形机身 + 提手 + 同色机壳 + 橙色线轴盖，是 MoMA、伦敦设计博物馆、Cooper Hewitt 的馆藏级设计符号，1970 年获 Compasso d'Oro。红 + 楔形 + 提手的组合一眼即认，是本案最危险的单一设计。
- **Selectric（次高风险）**：1961 年推出，设计师 Eliot Noyes，高尔夫球形打印头 + 弧形机壳，1986 年品牌停用，累计售出 1300 万台。球形打印头本身是功能件（功能特征不受商业外观保护），但**整体机壳造型**具识别性，仍有争议空间。
- **Lettera 22 / 32（较低风险）**：造型相对通用，外形风险低，风险主要在“ Olivetti / Lettera”名字本身。

## （3）著作权角度：四类分开算

- **实用物品外观**：打字机整体造型属功能性实用物品，著作权不保护其形状本身（美国 *Star Athletica* 可分性测试：只有可独立感知的艺术特征才受保护，机身造型难满足）。中国司法实践对外国实用艺术作品按 25 年口径（如适用）——1960 年代机型也已过期。
- **他人照片**：摄影师享有照片著作权，网上找 Valentine 实物图直接用作素材 = 侵权。必须自拍、自绘、自渲染或用明确授权图。
- **自行 3D 渲染**：渲染行为本身不侵犯著作权（底层实用设计无著作权），但渲染结果若 1:1 还原标志性外观，仍落入商标 / 商业外观风险。**渲染不是避风港。**
- **AI 生成近似外观**：责任跟输出走，不跟工具走；AI 生成的 1:1 近似外观与人工临摹同等对待。且 prompt 里写品牌名、型号会留下“故意模仿”的证据链——**prompt 必须禁用一切品牌名与型号名**，生成后做人工比对审查。
- **字体附带**：美国不保护字体本身，但字体文件受著作权保护——用已授权字体文件，不复制品牌铭牌字体文件；Courier 系等通用风格可用开源 / 已授权字体实现。

## （4）现有 App 的做法：无人用真名真机

- **Hanx Writer**：全部虚构机——Hanx Prime Select、Hanx 707、Hanx Golden Touch，后加 Matterhorn、Del Sol、Electric，**无一真品牌**。汉克斯本人是收藏家，曾把三台自藏真机借给开发商采样字体，但机器身份全部原创。这是标杆做法。
- **Printique**：通用复古机（“a vintage typewriter for your ideas”），无品牌名。
- **Rebi Typewriter**：通用复古机，明确声明与 Hanx 无关。
- **TypePress（补充发现）**：手绘通用机，字体用 Courier Prime、IBM Plex Mono 等公开字体名。
- **结论**：同行共识就是“时代原创”，不是保守，是标准解。

## （5）安全线验证：B + C 组合是否足以避开风险

**结论：可以做到低风险，不是零风险；关键在执行细节。**

**法理支撑**：
- 美国指示性合理使用三要件（*New Kids on the Block*）：① 不用该商标就无法指认；② 只用必要部分（纯文字单词，不用 Logo、特殊字体、配色）；③ 不暗示赞助 / 代言。**法院未把该抗辩扩展到 Logo 与产品外观——文字可以提，Logo 与外观不能抄。**
- 中国《商标法》第 59 条正当使用（描述性使用）+ 北京高院三要件（善意、不作为商标使用、仅为说明 / 描述）；2026 年修订据解读文章进一步明确了指示性合理使用（条文与生效以官方文本为准，律师核查）。

**执行清单（可直接落到美术与文案规范）：**
1. **机器命名**：原创时代名，如“红塑料便携 1969 款”“高尔夫球电动 1961 款”“上打式标准机 1900 款”，不出现品牌与型号真名。
2. **外观距离**：通用时代造型；拉开与标志性设计的距离——Valentine 不用“亮红楔形机身 + 提手 + 同色机壳 + 橙色线轴盖”这一组合；Selectric 不用球形打印头 + 弧形机壳的组合造型；Lettera 不用其铭牌布局与配色组合。
3. **史实文字**：只在成就 / 图鉴介绍页用纯文字提及品牌与年份（如“1969 年，Olivetti 推出 Valentine……”），不放在机器名、商店截图、图标、启动页；同页配“本应用与上述品牌无任何关联，亦非其赞助或代言”的声明；品牌名不用对方字体 / 配色突出显示。
4. **文字与外观分离**：提及真名的介绍页，配图用自家原创机，不要配 1:1 复刻图；否则文字 + 外观组合会放大混淆。
5. **AI 素材**：prompt 禁用一切品牌名、型号名；生成后按标志性元素清单人工比对。
6. **商店素材**：截图、介绍、关键词不出现品牌名——华为审核是独立风险通道，比法院更快。
7. **成就命名**：用时代 / 技术名（如“塑料革命”“高尔夫球时代”），不用品牌名。

**残余风险（即使做到以上）：**
1. 商业外观的边界是事实判断（公众是否认得出），没有安全港公式；Valentine 级别的符号即使改色改细节，若整体轮廓仍“一眼即认”，仍有争议空间。
2. 整套收藏若严格按真实品牌编年史排列，即便不写品牌名，也可能被主张“影射性使用”——缓解：打乱编年、混搭时代与虚构元素。
3. 中国《反不正当竞争法》第 6 条“有一定影响”的门槛低于注册商标，博物馆级设计可能被认定。
4. 华为 AGC 审核的自由裁量（可能要求提供授权或直接驳回品牌相关内容）。
5. 出海后的美国法商业外观与指示性合理使用需另行评估（本轮以中国上架为主场景）。
6. 字体文件、音效采样若取自他人素材另有版权（自录自采可避）。

## （6）若未来坚持用真名复刻：授权路径与成本量级

- **对口权利人**：Olivetti → TIM 品牌部门；IBM → IBM 知识产权许可；Triumph-Adler → 京瓷；Royal → Royal Consumer；Smith Corona → Smith Corona Inc.；Underwood → 随 Olivetti（TIM）；Olympia → Prygoda 系（复杂）；Remington → 无明确打字机承继人，基本不建议碰。
- **谈判要素**：品类（移动应用）、地域（中国 / 全球）、期限（通常 3–5 年）、范围（名称 / Logo / 外观是否全含）、样稿审批与品控条款。
- **成本量级（行业基准，非针对本案报价）**：版税通常为净销售额 3–10%（角色娱乐类 10–12%，品牌时尚类 4–12%，全行业 2–18%）；保底（MG）常见为预期版税的一半左右，知名品牌保底常见六位数美元起；另有签约预付（可抵版税）、审批与法务成本。
- **对本 App 的现实判断**：当前免费无内购 → 净销售额 ≈ 0，权利人要么不接、要么改收固定年费；对 TIM、IBM、京瓷这个量级的权利人，免费小 App 的授权问询大概率不回复或被拒；即使谈成，固定年费量级预计每年数万至数十万美元（量级估计，非报价），另加数月谈判周期与持续审批负担；华为审核仍可能要求出示授权文件。
- **结论：授权路线存在但性价比极低，仅在 App 有规模收入后再评估；现阶段不启动。**

## 风险分级表（三条线）

| 线 | 做法 | 风险等级 | 主要风险点 |
|---|---|---|---|
| **A 真名复刻** | 品牌名 + Logo + 1:1 外观 | **高** | 商标侵权、商业外观 / 装潢、华为审核下架 |
| **B 时代原创** | 原创名、无 Logo、通用时代造型、拉开标志性距离 | **低** | 残余：过于神似的商业外观争议、编年影射 |
| **C 史实文字** | 介绍页纯文字提品牌年份 + 无关联声明 | **低** | 残余：与高仿外观组合放大混淆、审核裁量 |

注：B 拉胯（做得太像）会把 C 也拖下水；文字与外观必须分离使用。

## 推荐

1. 收藏全部走 B：原创时代名 + 通用时代造型，按 §5 执行清单做美术规范，尤其 Valentine 与 Selectric 两组组合元素列入禁用清单。
2. 成就与图鉴文案走 C：纯文字史实提及 + 无关联声明，不进机器名与商店素材。
3. 三不红线：不上 Logo、不写品牌名于机器与商店素材、不做 1:1 标志性设计。
4. 不启动授权谈判；上线前律师过一遍机器图与文案清单。

## 需律师终审的事项

1. 各品牌在中国、美国、欧盟的商标注册现状逐项检索（中国商标网、USPTO、EUIPO），尤其 Selectric 在中国的注册现状、Olympia 现持有人与权利范围、Remington 打字机类商标是否已注销。
2. Valentine、Selectric 是否构成《反不正当竞争法》第 6 条“有一定影响的商品装潢”。
3. 每条成就 / 图鉴文案的正当使用三要件审查（定稿后逐条过）。
4. 2026 年《商标法》修订的最新条文与生效时间。
5. 外国实用艺术作品 25 年口径是否适用于本案机型。
6. 逐机型设计专利号核查（确认无仍在期的外观设计专利，尤其 1970 年代后期机型若纳入收藏）。
7. 机器设计稿与 Valentine / Selectric 的相似度比对（建议律师参与评审，而非仅凭美术直觉）。
8. 出海场景（Google Play / App Store）的美国法评估。
9. 华为 AGC 审核对品牌历史内容的现行尺度（可通过上架预审 / 咨询确认）。
