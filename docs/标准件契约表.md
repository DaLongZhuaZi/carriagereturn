## 1. 六项契约（§3.3 通式）

每件都写：① 几何（锚点／对齐／z 序／尺寸公式）② 材质 token ③ 变体维度 ④ 替换规则（五条）⑤ 动画行为 ⑥ 交互 affordance。

**替换规则五条**（全件共用，入库前逐条过）：几何偏差 ≤1vp；左上顶光 5500K；色板 ±10%；无 baked 文字（键帽图例＝Button 里的 Text，纸面文字＝Text）；无品牌／型号／logo。

## 2. z 序（§3.3 第 1 项）

机身面板 0 → 纸面板 1（色带条 1，后绘制）→ 横尺 2 → 落字导件 3 → 字篮 4 → 功能行 5 → 键盘网格 6 → 拨杆 7／旋钮 7 → 候选栏 8。

## 5. 与工具脚本的关系

- `tools/check-part-colors.py` 解析本表对应的 `.ets`：每件 3 个 `colorSamples`（相对坐标）与 `color` 比对，±10%。
- `tools/check-part-grain.py`：每件 5 个 64×64 区（中心＋四角内缩 10%），按**颗粒（高频残差）**判 ≤15%，同时打印 `maxmin` 作对照。
- `tools/check-part-geometry.py`：读契约里的几何常量与真机截图量测值比对（批 1 起用）；新增 `--measured`（真机量测 JSON）与
  `--caps-dump`（§10.2(a) 逐帽抽查：dump 的帽心 vs keymap CapDef，判据 ≤2%）。
- 批 1 实跑（产物在 `docs/evidence/`）：
  - `p24-grain-run.txt`：16/16 PASS（纸 4＋帽面 4＋按下态 4＋空格条 4，高频残差 ≤0.15）。
  - `p24-colors-run.txt`：纸面板 worst 8.7%、键盘网格 worst 3.7%（阈值 10%），FAIL 0；功能行无贴片按代码常量校验（SKIP）。
  - `p24-geometry-run.txt`：8/8 公式自洽偏差 0.00vp；实测 stageW 362.7／funcRowH 52.1 偏差 0.00；逐帽 **43/43** 帽心最大偏差 **0.07%**（判据 ≤2%）。
