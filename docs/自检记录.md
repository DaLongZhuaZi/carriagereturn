## 三件事 · 修改记录（2026-11-07）

### 第 1 件 页面切换
- 过渡从 PageShell 内层移到 **Index 8 个 if 分支根节点**：`transition(TransitionEffect.move(TransitionEdge.END).animation(250ms, EaseOut))`
- 主页渲染条件 `homeOpen` → **`navStack.indexOf('home') >= 0`**（栈里有 home 就常驻，滑入时底下是主页不是打字机）
- 主页去掉每次挂载的 `op 0→1`，首帧 op=1
- 结构证据：卷宗页在前时 dump 仍含「回车」「继续写作」；返回后「新建卷宗」节点消失（旧页已卸载）
- **首帧观感必须用户录屏**（screenCap 单帧 400-500ms > 250ms）

### 第 2 件 下拉菜单
- 删全屏 `rgba(0,0,0,0.35)` 遮罩 → 透明点透层；卡片 `opacity 0→1 + scale 0.96→1 + translateY 4→0`，160ms
- 像素证据（平板）：开菜单前后 左半屏均值 65.7→65.7（差 0.0）、底部 57.0→57.0（差 0.0）→ **底层未变暗**

### 第 3 件 新建卷宗（P0）
- **撤回 d975822 的「验证通过」**：那次只验默认名与「点卡片不关」，带名字创建从未验过
- 真根因：`AppDialog.op` 只在 `aboutToAppear` 置 1，而组件在页面挂载时就存在（那时 visible=false），
  visible 变真不会再触发 → **卡片 opacity 恒为 0（节点在树里但肉眼不可见）**；
  此前所有 dump 判据都把它当成「弹窗出现了」
- 修：`visible` 改 `@Prop @Watch('onVisible')`；删卡片上的 `.onClick(()=>{})`；
  输入框改非受控（`draftName` 改普通字段、去掉 `text:` 绑定）+ `defaultFocus(true)`
- 像素证据（平板卡片区亮字像素）：关窗 0 → 开窗 **3585**
- 打字链路：`uitest uiInput inputText 800 1211 第二卷宗` → `TEXT=第二卷宗` → 点创建 → 进内页、名字正确
- 手机：卡片区亮字像素 **14235** → 弹窗在手机上同样可见

## 主页按钮失效 P0 · 修复记录（2026-11-07）

### 根因
`dab1cb0` 把主页改为常驻挂载（`navStack.indexOf('home') >= 0`）防闪，但没动 Stack 顺序：
主页排在卷宗／换装／收藏／收藏详情**之后**，于是它盖在这些页之上——`pushPage` 正常、目标页也挂载，只是被不透明主页遮住。
上一批用「dump 节点存在」当验证通过是错的：dump 只能证明节点在树里，不能证明层级与可见性。

### 改动（只换位置，不动栈语义与过渡）
- 主页 if 分支移到**覆盖层最前**（打字机底座之上、第一个覆盖层）
- `AppMenu` 移到**最上层**（原被设置／导出／内页／文档视图盖住）
- 追加必要修正：**栈顶为 `typewriter` 时不渲染主页**，否则常驻主页会把打字机盖住（「继续写作」点不动）

### 覆盖层最终顺序
主页 → 卷宗 → 换装 → 收藏 → 收藏详情 → 设置 → 导出 → 内页 → 文档视图 → AppMenu
（内页盖卷宗、文档视图盖内页、收藏详情盖收藏、AppMenu 最上，全部满足）
