## 中文输入桥接 · 两台实测（2026-11-07）

### 根因（已证实）
系统输入法把提交串投给**锚点 TextInput**，不是 `InputMethodController`：

```
AceTextField: HandleOnPaste len:2
AceTextField: AddInsertCommand len: 2
MainScreen: cn anchor onChange len=2
（cn evt insertText 一条都没有）
```

### 修法
锚点 `onChange` 取增量 → `enqueueChinese()`（复用 40ms 拆字队列 + commitChar）；
缩短且无预编辑 → 按差值 `onDelete`；控制器订阅保留（不双重落字，实测无投递）。

| 注入「手机」 | — | `cn commit ch=手` → `ch=机` ✓ |
| 逐字节奏 | `left=1` → `left=0` | 同 |
