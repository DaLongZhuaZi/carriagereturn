## 一、资产清单（每项含授权状态）

### 1. 机器外观：开发期 AI 生成原创渲染图

| 资产 | 来源/工具 | 授权状态 | 结论 |
|---|---|---|---|
| 机器主体渲染图（hero、正面、侧面、键盘特写、纸面特写） | Midjourney 付费版 | 付费订阅者拥有产出、可商用；免费试用已取消（2023 年起无免费档），旧试用图仅 CC BY-NC、不可商用 | ✅ 可用，须付费订阅；年收入超 100 万美元需 Pro/Mega 档；Midjourney 不提供侵权赔偿，AI 图本身版权地位未定 |
| 同上（本地自托管路线） | FLUX.1 [schnell] | Apache 2.0，无限制可商用 | ✅ 最干净的免费路线，需 12–16GB 显存量化版 |

| 同上（禁用） | FLUX.1 [dev] / FLUX.2 [dev] | BFL 非商业许可（v1.1 已删去"产出可商用"那句）；用 dev 训出的 LoRA 也继承非商业限制 | ❌ 不得用于本产品管线 |

**风格一致性方法（已验证的公开做法）**：
- Midjourney：先定 1 张主风格图，用 `--sref` 锁配色/材质/光影；V7 用 `--oref`（omni-reference，可锁任意物体，不只人脸）把同一台机器带到各视图；固定 `--seed` 与 `--ar` 减少漂移；`--sw` 调风格权重。
- 本地 Flux：主图定稿后用 img2img / ControlNet（线稿/深度）控制角度与结构，换视图不变形。
- 关键工艺点：**键帽文字不要 baked 进 AI 图**（AI 极易把键帽字母画糊、画错），机器身体用 AI 图，键盘层用代码矢量绘制（可换中英键位、可缩放、文件小）；提示词必须带 `blank nameplate, no logo, no brand name, no text`，并用否定词排除品牌与水印。

**原创时代机路线（防 1:1 复刻）**：不要点名任何真实型号，改为 4 个时代原型：1920s 直立式座机、1930s 便携机、1950s 流线便携机、1960s 电动式；每台用不同的颜色 + 材质 + 键帽形状 + 机身轮廓组合，并留空白铭牌。即使模型见过真机，时代特征的重新组合也不构成对某一台名机的 1:1 复制；出图后须人工与参考照片比对轮廓与配色，撞脸（如红机身 + 特定圆角造型的 Valentine 式组合）即换方案。

### 4. 字体：英文打字机体 + 中文宋体系（逐个核实）

**统一结论：以下 7 款全部是 SIL Open Font License 1.1。** OFL 的打包 checklist 只有三条：① 随包附 OFL.txt；② 不得把字体文件本身单独出售；③ 修改版须沿用 OFL 且不得使用保留字（Reserved Font Name）。**嵌入 App 明确允许**（OFL 原文含 "embed"），且"把字体放进一个出售的软件"不算单独售字体——所以现在免费、将来内购都不影响字体授权。

|---|---|---|---|

### 5. 音效：实录优先，开放库兜底

**实录采样清单（按一台真机录制，全部自有版权、最干净）**：
- 按键敲击：10–15 个变体（不同键位、不同力度——真机字杆敲击声随键位而异），另录 3–5 个松键回弹声；播放时随机轮换（round-robin），避免"机关枪"重复感。
- 空格键：单独录，声音更闷更深（thock），3–5 个变体。
- 换行叮声（边际铃）：2–3 个变体，带自然衰减尾音。
- 回车杆：整套手势一次录全（滑动 + 滚筒 zip 声 + 到位顿挫），另拆一段单独的 zip 声备用（若做可拖动的杆）。
- 走纸：滚筒旋钮棘轮声、塞纸沙沙声、抽纸声。
- 换档（Shift 篮筐抬升）：2–3 个，较沉的顿挫声；退格：2–3 个（可选）。
- 录制规格：安静房间、48kHz/24-bit WAV、近距离话筒 10–20cm、每采样录 5 遍挑最好的、峰值归一化到 -1dB；App 内用单声道 44.1kHz WAV（小采样解码零延迟）或 OGG，总预算 <2MB。
- 权属：用自己的机器录，音频版权即归你；借他人机器需机主同意（音频本身不含品牌外观，无商标问题）。

**开放授权库（实录前的占位 / 备选，需逐文件核协议）**：

| 来源 | 协议 | 商用结论 | 注意 |
|---|---|---|---|
| Freesound（单文件协议） | CC0 / CC BY / CC BY-NC / legacy Sampling+ | CC0 ✅ 无需署名；CC BY ✅ 需署名；**CC BY-NC ❌、Sampling+ ❌ 严禁用于本产品** | 必须逐文件打开详情页核协议，禁止按标签批量下载；署名用站内 attribution 工具生成清单；下载需账号（由父 agent/用户侧处理）；站方 ToS 另有限制门户商用的条款，与单文件 CC 协议是两回事 |
| Freesound 已验证 CC0 的打字机实例 | ramsamba「Typewriter bell + carriage」（铃 + 回车）、yottasounds 单键系列、Zentone「Typewriter」 | ✅ CC0（多方引用交叉印证） | 仍建议入库前再点开详情页复核一次（上传者可改协议） |
| ZapSplat 免费版（Basic） | 站方标准许可 | ✅ 可商用，但**必须署名**（App 内"设置 → 关于 → 音效致谢"页即可，如 Desktop Ducky 的做法）；仅 MP3、有下载量限制、需账号 | ⚠️ 条款有"音效不得为项目的主要价值"一句——打字机 App 的价值是整体体验而非单卖音效，属可解释范围，但不如 CC0 干净，列为次选；付费版可去署名 |
| Pixabay 音效 | Pixabay 许可 | ✅ 可商用、无需署名 | 禁原样再分发；可作次级备选 |
| 未核实来源（如 BBC 等） | 未查 | ❌ 不要默认采用 | 使用前单独核协议 |

**BY-NC 的特别提醒**：即使 App 当前免费无内购，也要把 BY-NC 当禁区——CC 的"非商业"指"不以商业利益为主要目的"，而本产品有激励计划收益预期、未来还可能上内购，BY-NC 在此不成立。现在禁掉，省得将来换授权。

## 二、推荐管线（按执行顺序）

1. **锁风格板**：先写一页风格规范（时代、材质、配色、光影、背景、纸色）+ 1 张主风格图；之后所有生成都引用它，这是"美术优先"能一眼统一的前提。
2. **机器**：Midjourney 付费版（`--sref` 锁风格 + `--oref` 锁同一台机器）或 Flux schnell 自托管；每台机器先出 3/4 hero 图定稿，再衍生正面、侧面、键盘特写、纸面四视图；键帽文字一律代码矢量层，不 baked 进图。
3. **纸张**：底纹用 Poly Haven / ambientCG 的 CC0 纸面或程序化噪点；格线、边距、红格、页眉代码画；明信片与便签图案走 AI 生成。
4. **字体**：按上表打包 OFL 字体 + 每款附 OFL.txt；中文字体只进 Regular（+Lite）并子集化；建一份资产授权清单（文件名、来源、协议、来源链接）随仓库走，商店审核与日后审计都用得上。
5. **音效**：实录为首选（清单见上）；实录到位前用 Freesound CC0 占位；任何 CC BY / ZapSplat 素材进"设置 → 关于"致谢页；BY-NC 与 Sampling+ 永不入库。
6. **用户导入自定义内容**：导入功能本身不产生版权问题（用户自担其素材授权），但 App 不得默认内置他人素材；导入字体/纸张时在界面写明"请确保你有权使用该内容"。

## 三、风险点（按严重度）

- **R1 AI 撞脸名机**：生成模型见过真机，可能复现某款名机的标志性组合（如特定红机身 + 圆角造型）。缓解：时代原型重组 + 空白铭牌 + 出图后人工比对参考照片，撞脸即换方案；不要把任何 AI 图注册为商标（AI 图版权地位未定，别人也能生成类似图）。
- **R2 Flux dev 陷阱**：dev 系（含 Kontext dev、Fill-dev）是非商业许可，v1.1 后连"产出可商用"的口子都收了；只用 schnell（Apache 2.0）或 Pro API，dev 训的 LoRA 也不能商用。
- **R3 Midjourney 收入线**：年收入超 100 万美元必须 Pro/Mega 档；且 Midjourney 不赔偿侵权、无版权背书，条款会变，商用前以官网原文为准。
- **R4 Freesound 按文件核协议**：站内无统一授权，混进一个 BY-NC 就会污染整包；入库流程必须含"打开详情页截图/记录协议"一步，禁止标签批量抓。
- **R5 字体保留字与体积**：Plex、Source、霞鹜/LXGW 是保留字，改版改名不得碰；中文字体全量 10–21MB，必须子集化 + Lite 版，否则包体先失控。
- **R6 Special Elite 协议标注冲突**：个别次级页面误标 Apache/ASL，以随包 OFL.txt 为准，打包时记录字体版本号与 OFL.txt 哈希。
- **R7 Commons 照片勿嵌入**：CC BY-SA 的 share-alike 与闭源 App 冲突；参考照片只看不取，真要嵌入只用 PD/CC0 并留档。
- **R8 ZapSplat 灰区**："音效不得为项目主要价值"一句在打字机 App 上可解释但不干净，且免费版强制署名、仅 MP3；列为次选，优先 CC0 与实录。
- **R9 纹理再分发灰区**：Pexels/Pixabay 禁原样再分发；用户导出信纸图时纹理接近原样出包，CC0 与程序化可彻底避开。
- **R10 录音机主同意**：借他人机器录音需机主同意；自己的机器最干净。

## 四、需父 agent / 用户确认的事

1. 机器渲染走 Midjourney 付费版还是 Flux schnell 自托管（后者免费但需 GPU 与搭建时间）？
2. 实录用的真机来源：用户自有机器，还是需另找机主/收藏者？
3. 是否接受 App 内设"音效致谢"页（接 CC BY / ZapSplat 时必需；全 CC0 + 实录则可不设）？
4. 中文字体首发是否接受"宋体子集 + 楷体 Lite 子集"的体积方案，还是要全量字库？
