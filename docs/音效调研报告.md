# 回车 CarriageReturn：公开可商用打字机音效深度调研报告

> 调研员交付（2026-11-03）。**结论先行：占位方案已闭环。** 仅凭直接核实过的 CC0 素材就能拼出一套完整打字机音色：按键床 + 空格单键 + 四个独立边际铃 + 铃+回车组合，全部来自 BigSoundBank 与 Freesound，无需署名、可商用、可再分发。CC BY 素材进致谢页后可用作第二梯队。Mixkit、Pixabay、ZapSplat、99Sounds 一律只能随编译后 HAP 二进制发行，**绝不能以 loose 文件形式提交到公开 MIT 仓**。另有两条流程级实锤：Freesound 上传者确实可以改协议（站方自 2017 年起保留 license history），以及 **Freesound API 免费档仅限非商业用途**——商业 App 必须走人工网站下载，不能用 API 自动化拉取。

> 说明：本报告不是法律意见。分级标准：Tier 1 = 我方直接打开详情页核实到协议徽标/原文；Tier 2 = 第三方清单或搜索摘要引用，入库前必须逐页复核；Tier 3 = 未核实，不得直接入库。

## 四、站方许可核查结论（ToS 与单文件协议的区别是关键）

- **Freesound（单文件 CC 协议为准，但有两条平台级陷阱）**：
  1. **上传者确实可以改协议——本轮已实锤。** Freesound 官方博客（2017 年社区更新）原话：站方保留 sound license history，因为“you may have downloaded a sound under one license, and when you go back to check its status some months later the license may have changed!” 站方会告知你下载时该声音的协议。因此入库规则：**下载当刻截图/记录协议 + 日期 + 文件哈希**，这份快照就是权利证据；CC 协议本身不可撤销，但快照是应对争议的唯一凭证。
  2. **API 免费档仅限非商业用途——本轮以官方 ToS 原文核实**（https://freesound.org/help/tos_api/ 及 API 文档）：“You can use the Freesound API for free only for non-commercial purposes. To use the Freesound API for commercial purposes, please contact us”；商业 API 使用须与 UPF 逐案谈判，且 API 许可本身不可转让、不可再许可、可随时撤回。**结论：声音的 CC 协议 ≠ API 的使用条款。** 回车 App（有激励收益预期）绝不能用 API 自动化批量拉取；正确路径是人工经网站下载（Freesound 下载需登录账号，由父代理/用户侧人工完成）。
  3. 附带风险：Freesound FAQ 警告，同一声音被他人原样用进歌曲后可能触发 Content ID 误认——保留来源记录即可申诉。
- **ZapSplat Standard License（2026-05-08 更新）**：Basic 免费档全球、永久、非独占，可用于无限个人、商业、广播项目；但**署名必需**（须在项目本身中清晰致谢，如 App 内致谢页，不能只发社交媒体）；免费档仅 MP3 + 下载限额；音效必须嵌入、同步，**不得作为项目的主要价值**（条款以“音效 app”为例——对以声音为核心体验的打字机 App 而言属灰区；ZapSplat 自身 FAQ 称游戏、应用内增强用途均可，但仍只能列为次选）；不得以任何形式分享、分发音效文件，不得 Content ID 登记，不得改编成新音效对外销售、分发。另有部分条目走 CC BY 4.0 许可类型，须按条目页区分。
- **Mixkit SFX Free License**：商用可、无需署名，但禁 standalone 再分发（不得单独、作 stock、放工具或模板、随源文件）；仅二进制内发行；18 岁以上条款、禁脚本批量抓取；注意 SFX 许可点名视频游戏，音乐许可不同（排除游戏、电视、广播），勿混淆。
- **Pixabay Content License**：商用可、无需署名、可改编，但禁 standalone 再分发；2019-01-09 前内容理论上是 CC0，但上传日期不可靠验证，**一律按 Content License 处理**；有目录注释提醒交互、软件用途须在 live 页确认。
- **99Sounds Free Licence**：商用可、无需署名、无需注册，但不得作为另一音效库或虚拟乐器的一部分再分发、转售（同样仅二进制内发行）；目录以电影、braam、科幻、城市音效为主，未发现打字机包，相关性低。
- **BigSoundBank**：CC0/WTFPL/公开域 dedication，可商用、可编辑、可再分发（含放进自己的游戏、应用、音效库），无需署名——是全场最干净的站方口径。
- **Chosic**：track 页口径（免费、无需署名、商用变现亦可）与站内通用署名文案矛盾，见 Tier 2 处理。

## 五、CC BY 署名清单做法

- 用 Freesound 每文件页提供的署名文本生成署名行（不要手写改写作者名与标题）；OGA eklee 如采用，署名格式为：Single Key Press Sounds by eklee, qubodup，Copyright 2012 eklee。
- 每包建 SOURCE.txt：来源链接 + 下载时协议快照 + 文件哈希 + 切分记录（仿 SoundType 做法）。
- App 内承载页：**设置 → 关于 → 音效致谢**，承载全部 CC BY 与 ZapSplat（如采用）致谢；CC0 无需署名，但保留来源清单以备商店审核问询。
- 当前署名清单（采用即进致谢页）：ddohler《Typewriter.wav》、YleArkisto《Kirjoituskone…Triumph Matura 300》、eklee《Single Key Press Sounds》（如采用）。

## 六、建议的占位方案（第一梯队先行，实录到位后逐步替换）

1. **按键主体**：BigSoundBank Hermes 打字床（s2838）切分出 10–15 变体 + BMacZero 单键（160678）做瞬态层；lyricalgirl 床（788956）作第二台机变体。
2. **空格**：BigSoundBank 空格单键（s2843）直接用，无需切分。
3. **行末铃**：四个独立 CC0 铃任选主备——ramsamba 318687、knufds 345955、MasterNavigator 444813、BigSoundBank s2844；MasterNavigator 一件注意归一化（峰值 -1dB）。
4. **回车杆/走纸**：knufds 345955（铃 + 回车复位一体）为主；YleArkisto 271525（CC BY，进致谢页）切分出手动回车与卷纸作补充。
5. **次选（仅二进制内发行，绝不进公开仓）**：ZapSplat、Mixkit、Pixabay、99Sounds 的打字机条目——且 ZapSplat 因“不得为项目主要价值”灰区排最后。
6. **入库流程铁律**：① 人工网站下载，禁用 Freesound API 自动化；② 下载当刻记录协议快照 + 日期 + 哈希进 SOURCE.txt；③ CC0/CC BY 文件可进公开仓，Mixkit/Pixabay/99Sounds/ZapSplat 文件只进编译产物；④ Tier 2 与未核实项在入库前必须人工打开详情页复核徽标；⑤ 资源文件名去品牌化，品牌名只留在 SOURCE.txt 来源记录里。

## 七、残缺口与缺口

- OGA《typewriter-sounds》、ramsamba 318686、tams_kp 43558 三处直接打开遭 403，未能当面核实，**不要重复请求被拒的 URL**，入库前由人工在浏览器打开详情页复核。
