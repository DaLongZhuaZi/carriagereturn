## 任务 1：横尺三角改红、位置分明（audit A2＋C2）

- 现象：横尺三角渲染为黑色（代码 `.fill('#c8322d')` 未生效），
  且左三角与中央指针挤在同一 x 位（1761 中央裁切见两枚黑三角叠放）。
- 做法：
  1. 查 `Carriage26.ets` 三角 Path（L217、L220）填充未生效的原因
     （是否被刻度 Path／锯齿 Row 盖住、是否缺 `fillOpacity(1)`、是否被父级 clip 裁掉），
     修到三角真正显示红色 `#c8322d`。
  2. 核对三角 x 计算式 `(PAPER_LEFT + 25 - (CX0 - 350))` 与中央指针 x 是否重合；
     若重合，把左三角改到纸左缘（156vp），右三角改到纸右缘（376vp），
     三枚三角（左／右／中央指针尖）位置分明、不叠放。
- 算过：V=0／行中／行末各一张横尺特写（1780–1782），三枚三角均为红、
  位置分明；像素量测确认横尺区有红色像素（不要只凭目视）。

## 任务 2：拼音残留字母不上纸（audit A3＋B2）

- 现象：拼音会话残留字母（"nij"／"jao"）未转换／未清空就落字，纸面出现 `aaaaaaanij好,`。
- 做法：修输入法缓冲——拼音字母要么选词上屏、要么退格清掉；
  换词／退格／换行时清空残留缓冲，原始拼音绝不以原文留在纸上。
- 算过：连续输 3 个中文词（如 你／好／吗），纸面无残留拼音字母；
  中途退格／换词后缓冲清空；截图＋dump 核对（1783–1785）。
