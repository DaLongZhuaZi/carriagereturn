# 手机操作手册（桌面端自足操作规范）

> 立规背景：桌面端多次在手机操作上卡住后直接找用户（点一下、给个坐标），
> 而这些坐标本来都能从代码／截图／dump 里自己算出来。
> **铁律：永远不让用户帮你点、永远不让用户给你坐标。**
> 用户只做只有他能做的事（真机手感、声音、左边缘手势、读屏听感）。
> 坐标与方法一律自己取证、自己验证、记进本文件，下次直接用，不再重算。

## 0. 设备与坐标系

- 唯一测试设备：手机 ADA-AL00U（Nova 12 Ultra），USB 连接，target `2UCUT24724009680`。
- 屏幕：**1224×2776 px**，vp2px = **3.375**。所有坐标一律用**原生 px**（1224×2776），
  除非特别说明。截图是原生 1224×2776；录屏是 848×1920（缩放 ×0.693），
  视频里量的 px 要 ÷0.693 才是原生 px。
- 换算：px = vp × 3.375；vp = px ÷ 3.375。

## 1. 取坐标的梯子（按顺序走，不许跳级问用户）

1. **dumpLayout 优先**：`uitest dumpLayout`（或同等布局 dump）拿元素的 bounds，
   点中心。能 dump 的一律 dump，**不许目测**。
   - 主页底部导航 Row 的 id 是 `home__bottom_nav`，直接按 id 找。
2. **截图量测**：dump 不到时，截原生图，用像素阈值／行列统计量出元素的
   实际包围盒，点中心。**不许目测估数**——要算出来（亮像素行带、列带、
   边缘阶跃），量完把数写进 §3。
3. **代码算**：布局是确定性的。读源码算出几何（行高、列宽、边距、padding），
   再用一张截图锚定一个参照点（例如菜单卡片左缘、纸左缘），推出其余点。
   例：AppMenu 三项各 48vp=162px，行距 162px；主页底部导航五项各 layoutWeight(1)，
   每项宽 1224/5=244.8px。
4. **hilog 验**：点完立刻截屏＋dump＋看 hilog，确认动作生效（onPick／页面切换／
   落字）。没生效就诊断（见 §2），**不许直接找用户**。

## 2. 点完没反应时的诊断顺序（不许跳过）

1. 截图确认：点的是不是目标元素（行带／列带对不对，差一行就是 162px）。
2. 坐标空间：确认用的 px 是原生 1224×2776，不是用视频 848×1920 的数直接点。
3. 遮罩：菜单有全屏透明点透层，点在卡片外（x<卡片左缘 或 x>卡片右缘，
   或 y 在卡片外）只会关菜单、不导航。点必须落在卡片内、目标行内。
4. 入场动画：菜单出现有 160ms 淡入＋缩放 0.96→1＋上移 4vp。菜单刚开就点会打偏，
   **开菜单后等 ≥200ms 再点**。
5. 点按方式：优先用 **uinput 点按**（快速连打已证可靠）；uitest click 偶发整屏失效，
   失效时 `aa force-stop`＋重启 App 再试，**不许因此找用户**。
6. 再试一次：按 dump 的 bounds 中心重打一次。两次都失败才在记录里写清
   "试过的方法＋原文错误＋dump/截图证据"，报阻塞——**阻塞也不等于找用户点**，
   等用户定夺下一步（例如换验证方式），不是让他上手操作。

## 3. 已验坐标（原生 px，1224×2776；测自截图，见括号）

### 3.1 打字机页顶部栏

- 文件夹图标：(101, 242)
- "?"（引导）：(980, 242)
- 汉堡菜单（开菜单）：**(1123, 242)**（测自 1357）

### 3.2 下拉菜单 AppMenu（打字机页，汉堡打开后）

- 菜单卡片：x 644–1184，宽 160vp=540px，右距 12vp=40.5px；
  三项各 48vp=162px，行距 162px；文字左起 x=700（左 padding 16vp=54px）。
- **收藏：(748, 436)**——行 y 355–517（测自 1357）
- **设置：(748, 598)**——行 y 517–679（测自 1357）
- **导出：(748, 760)**——行 y 679–841（测自 1357）
- 点这三个数（文字中心）即中；行内任意 x（644–1184）＋行内 y 都可。
- 注意：点菜单外任意处只关菜单、不导航。

### 3.3 主页底部导航（HomePage，Row id `home__bottom_nav`）

- 五项各 layoutWeight(1)，每项宽 244.8px；行高 56vp=189px，贴底（下距 bottomInset）。
- x 中心（已定，不依赖 bottomInset）：
  - **卷宗：122**
  - **收藏：367**
  - **换装：612**
  - **设置：857**
  - **导出：1102**
- y 中心 = 2776 − bottomInset_px − 94.5。实测 2026-11-15：`home__bottom_nav`
  bounds `[0,2493][1224,2682]`，子项文字 bounds y `2558–2617`，**y 中心 2588**；
  直接点 `(目标 x, 2588)`，之后不再重算。

## 4. 维护规则

- 每验出一个新坐标／新方法，**当批就写进 §3**（附测自哪张截图／哪个 dump），
  不许只记在自检记录里——自检记录是流水账，本文件是操作手册。
- 坐标变了（布局改了）就更新本文件，旧数删掉，不留两套。
- 本文件与自检记录同批提交＋push origin main＋验真。
