## 任务 2：装纸改从滚筒进纸（binding，主项，取代批 43 的下滑方向）

- 按增补-11 §2：装纸是纸从滚筒处向上"长"出来，不是整张从屏幕上方滑下来。
  - t=0：纸的下缘固定在滚筒处（y≈362），纸高 0（纸不可见）；字车在行首、光标隐藏、标题不显示。
  - t=0–600ms：纸的上缘从 y≈362 向上移到 56vp（ease-out），纸高从 0 长到 306vp。
  - t=600ms：纸到位（上缘 56vp、高 306vp）；随后 150ms 内标题与光标淡入。
- 出纸是逆过程：标题与光标先淡出（150ms），纸的上缘从 56vp 向下移到 y≈362（ease-in），
  纸高从 306vp 缩到 0，纸缩回滚筒里。
- 进纸（回车换行，250ms）不动。
- 触发点不变（App 启动／新建／切换／关闭）。
- 算过：装纸四帧（1900–1903，t=0／200／400／600ms）：纸是"从滚筒处向上长出来"的
  （下缘始终在滚筒处 y≈362、上缘向上移、纸高从 0 长到 306vp），每帧写纸上缘 y、纸高、
  标题／光标状态；出纸三帧（1904–1906，t=0／300／600ms）：纸缩回滚筒里。
