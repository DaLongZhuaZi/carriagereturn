## 字车条平移宽图（§2.1 be069ea 口径，2026-11-04）

### 诊断（先做，已出结果）
- 设备实为 **MLR-AL10**（非 MatePad）；当前 HAP 含 48c4c9b + 本轮改动。
- hilog 实测 `recalcTravel`：max=174.00、perChar=4.047、cpl=43（stageWidth 497、边距 28）。
- 慢速 1 键/秒连打，`carriage offset ->` 逐字递减：−43.16 → … → −174.33（每字 4.05vp，到 −maxTravel 钳制）。
- **48c4c9b 已知问题的复核**：该版本 maxTravel 仅 64vp（每字 1.49vp），像素互相关实测 10→20 字照片左移 35px、10→40 字 106px，与行程值吻合 → **旧版偏移其实在动**；MatePad 上「偏移 0」不可在本机复现，最可能是对方装的是 48c4c9b 之前的 HAP，或截图发生在自动换行之后（换行会归零）。
- 连点丢键：1 键/秒的慢速节奏下 43 次点击落 43 字（未丢）；0.3s 节奏仍会丢，属注入过快。
