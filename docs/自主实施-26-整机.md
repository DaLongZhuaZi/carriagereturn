## 铁律（违反即返工）

- **开工前必须先 pull 到最新 main**（见第 0 步）。定案写在仓里，不 pull 就看不到。
- **永远不让用户帮点、永远不让用户给坐标。** 新页面的点按坐标从源码几何算（坐标梯子：源码几何 → 截图量测 → hilog 打点），手册 `docs/手机操作手册.md` §3 有已验坐标。用户只定工作、不定方法。
- **已定的方法是定案，不许质疑、不许重新谈判、不许拿给用户二选一。** 方法到限走设计里写好的兜底、记不符点。26 号稿 v2 已批准，修正 1–3 是本次 binding 裁决，不许重议；键帽＝生成帽身＋ArkUI Text 叠加图例、图例不 baked 进图、图例上移 5.0vp、黑井 z 4.0 盖钢板，全部是已定的点选，不许重议。
- **一口气做完。** 每做一个小项就停下写 PARTIAL 报告等"继续"是不许的（第 19 批旧会话的教训）。任务＋验收全部做完再交一份批报告。
- **验收只写"做到什么算过"。** 绝不写"缺一项不许点"式硬门槛。某项证据抓不到时，用替代证据继续做，并在批报告里写清缺了什么、为什么缺、替代证据是什么。只有编译不过、设备离线、包装不上这三种情况可报阻塞，报时附试过的方法和原文错误。
- **一次任务、一次交付；中间可本地提交做检查点，但只 push 一次（最终），push 前全量验收通过。** 结束 push＋远端验真（`git ls-remote` 看 HEAD），不许只 push 不验。批报告的不符点如实记，不许拿"PARTIAL"当"PASS"交。
- **测试只在手机 ADA-AL00U 上、USB 连接进行**（USB target `2UCUT24724009680`）。平板不再是测试设备。
- **声音测试暂停**：不做人耳听音、不验音效本身。hilog 里的声音打点可看，只证明编排走到那一步，不算声音测试。
