# 26 号稿增补-22：批 57——横尺刻度线重做为预渲染贴图

> 依据：用户 2026-11-19 22:48–22:49 反馈——批 56 截图（2110／2113）里"划线的素材"与"固定的刻度线"看上去很怪，需要优化。沙箱读码＋识屏确认：怪的是**横尺（Carriage26 内，700vp 宽）上的两组线**——① 刻度线（`rulerTicksPath()`，Path 画的细线）；② 锯齿下沿（175 个纯黑矩形 Column）。两者都是运行时代码画的线，抗锯齿差、没有层次、没有质感，合起来像"虚线＋条形码"，不是一把真尺子。本批把横尺的"杆＋刻度＋锯齿"三件合成一张预渲染 PNG，一次替换。

## 一、根因（沙箱读码核实，Carriage26.ets 约 193–225 行）

现行横尺是一个 700×12vp 的 Stack（`clip(true)`，位置 `cx()−350`、`RULER_Y`，随字车整体位移），内含四件：

| 件 | 实现 | 为什么怪 |
|---|---|---|
| 杆身 | Column 700×12vp，运行时 `linearGradient`（`#e6e6e8 → #b4b4b4 → #7d7d80`） | 渐变本身尚可，但它是"光"，按增补-6 应进贴图；更重要的是它与刻度、锯齿分属三件，质感不统一 |
| 刻度线 | `Path({ commands: rulerTicksPath() })`，`.stroke('#3d3d40').strokeWidth(0.8)`；每 4vp 一根、全部同长 5vp、从 y=0 画到 y=5 | 全部同长同粗、没有主次刻度，0.8vp 细线在真机上抗锯齿差，渲染出来像一条断断续续的虚线；且只在杆身上半部，没有一把尺子该有的"长短刻度"层次 |
| 锯齿下沿 | Row（`space: 2vp`）＋ `ForEach(teeth())` 175 个 Column，每齿 2vp 宽 × 3vp 高、`.backgroundColor('#2b2b2f')`，位置 y=9vp（占 Stack 底部 3vp） | 175 个纯黑扁矩形、零明暗、零倒角，视觉上就是一排条形码；真尺子的齿是金属件，应有受光面与阴影面 |
| 边距红三角 | 两个 TriMark26（`#c8322d`），y=6vp，标纸左右缘 | **不动**——它们位置随纸走、是功能标记，不是"线"；本批不碰 |

另：`sawPath()`（约 133 行）定义了但从未被调用，是死代码；`rulerTicksPath()`、`teeth()` 在本批后也不再被调用。

## 二、修法：三件合成一张贴图

新素材 **`ruler-steel-v1.png`**（沙箱已生成并推仓，见 §三）：

- **尺寸**：2800×48px，即 700×12vp @4x（与 Stack 等大，1:1 叠加，`ImageFit.Contain`，不拉伸）。注意 Stack 高只有 12vp（齿在底部 3vp 内，y=9–12vp），**不是 15vp**——贴图若做成 15vp 高，底部 3vp 会被 Stack 的 `clip(true)` 裁掉。
- **杆身**：纵向渐变，与代码原值一致（`#e6e6e8` 顶 → `#b4b4b4` 45% → `#7d7d80` 底），预渲染进贴图（增补-6：柔边渐变一律预渲染 PNG，运行时只做 1:1 叠加）。
- **刻度**：主次分明。次刻度每 4vp 一根、4vp 高、2px 宽、`#3d3d40`；主刻度每 20vp（每 5 根）一根、7vp 高、3px 宽、`#2b2b2f`；每根刻度下方带 1px 浅色高光（`#ebebee`），做"刻进去的槽、槽底 catch 光"的效果。刻度从杆顶（y=0）向下画。
- **锯齿**：在贴图底部 12px（y=36–48px，即 9–12vp），175 齿、每齿 2vp 宽、2vp 缝、3vp 高。齿形为上窄下宽的梯形，底色深钢 `#3a3a3e`（不用纯黑 `#2b2b2f`，去条形码感），每齿顶部 1px 高光（`#78787e`）、底部 1px 阴影（`#1c1c1e`），读作金属齿而非黑条。

代码改动（`entry/src/main/ets/components/type26/Carriage26.ets`，横尺 Stack 约 193–225 行）：

1. 删杆身 Column（运行时 linearGradient）、删 Path 刻度、删锯齿 Row（175 个 Column），三件合为一张：
   ```ets

     .width(700 * this.sx).height(12 * this.sy)
     .objectFit(ImageFit.Contain)
     .position({ x: 0, y: 0 })
   ```

2. **保留**两个 TriMark26（边距红三角，y=6vp，位置公式不动）——它们叠在贴图之上，仍标纸左右缘。
3. Stack 本身不动：宽 700×高 12vp、`clip(true)`、位置 `x: this.cx() - 350 * this.sx, y: RULER_Y * this.sy`、随字车位移（`translate({x: offsetXVp})` 在外层容器，不动）。
