## §5 三端形态（都按折叠渲染图的路子：整屏一台 3D 机器）

| 端 | 形态 | 布局要点 |
|---|---|---|
| 直板机（手机竖版） | 整屏一台打字机，正面微俯视 | 纵向五区：顶栏黑区→纸区→字车区→字篮井区→键盘区；机器满幅贴边（主目标图） |
| 平板（竖版） | 整屏一台打字机，正面微俯视 | 同一直板机五区，机器更大、零件更舒展 |
| 折叠半开 | 上半屏纸、下半打字机 | 铰链在中部；上半是黑底上的纸（卷过滚筒），下半是字篮＋键盘（折叠深棕图） |
| 折叠外屏 | 紧凑布局 | 唯一例外：外屏紧凑布局，功能须在菜单里同等可达 |

三端同一台机器、同一套零件语言；差别只在机器怎么摆（整屏／分两半／紧凑），
不在零件长什么样。

## §7 逐件设计

### §7.1 纸

- 颜色：奶油色，实测 (226,220,204)～(241,236,224)，暖白。
- 宽度：约机宽 60%，居中；左右各露约 20% 机身（滚筒两端＋旋钮）。
- 顶部卷曲：纸顶边卷过滚筒，卷筒的圆柱面＋阴影看得见。
  A 档为主：生成图只做"卷曲的滚筒＋纸顶"（静态覆盖层，固定在滚筒顶），
  纸文用活的 Text／Canvas 叠在纸面上；进纸时纸文与生成图同向移动
  （生成图随纸顶走，卷曲始终贴在滚筒顶）。
  B 档触发条件：A 档生成失败且兜底件也未达标时，降档为压暗带
  （宽 12vp、透明度 0.35、贴纸顶），门二的"顶部卷曲可见"改为压暗带的
  可测定义（压暗带宽 12vp ±2vp、透明度 0.35 ±0.05）。
- 纸面微皱／纹理极轻，不抢眼；纸文由文档内容实时生成（生图的纸文
  只是示意）。

### §7.2 滚筒

- 颜色：深钢色（近黑金属），带纵向拉丝；9 档柱面明暗罩（批 2 已交付，
  批 31 已恢复挂载）继续承载明暗，不新增渐变（25 号稿 §2.5）。
- 可见部分：纸后基本藏住，只露两端——左端筒身＋旋钮、右端筒身＋旋钮。
- 旋钮：滚花金属旋钮，直径 46.5vp live（沿用现行值——与滚筒高 44.9vp
  匹配；拆解"纸宽 1/8"为目测概数，以 live 值为准），钉在滚筒两端轴上；
  点按旋钮进纸一行（Q15(a) 已定，底层复用）；双旋钮均可点按。

## §8 功能 → 零件映射（打字页面）

任何功能不得用悬浮按钮、底部抽屉、系统弹窗承载。

## §9 前端架构与复用

### §9.1 分层

打字页面分三层，自下而上：

1. **底层（复用，不动）**：打字引擎、输入法（拼音词库 v3.1）、文档模型、
   成就判定、导出、音效、纸模型、字车逻辑。只改它们长成的零件，不改

2. **零件层（本稿新增）**：§7 的全部零件——纸（卷曲）、滚筒＋双旋钮、

   动画时序沿用现行（打击 85ms snap、进纸 300ms EaseInOut、换行

## §11 验收门

验收以用户目视＋截图量测为准（桌面端自述多次被实码推翻，须亲自读码／
看图复核；像素差为 0 即没动，不许报「已移动」；动画宣称须有到达屏幕的
帧或录屏；验收只写「做到什么算过」，绝不写「缺一项不许点」式硬门槛）。

- 门一（整机感）：打字页面一眼读作一台真打字机，盖子满幅贴边，无悬浮
  UI 板、无系统弹窗承载功能。目视检查点：五区齐全、无悬浮 UI、满幅贴边。
  用户目视 Gate 3。
- 门二（纸）：纸 V=0 左缘 156vp ±2vp，顶部卷曲可见，滚筒两端＋
  双旋钮可见。截图量测。
- 门三（字篮）：扇形井为曲线口（非矩形），扇子陷进井里，井边有阴影缝，
  枢轴可见。可测 proxy：扇形井口曲线矢高 ≥8px，井边阴影缝宽 2–4px。
  用户目视。
- 门四（键盘）：5 行真键盘＋黑井＋键杆＋红 RETURN；键帽 3D（顶面＋
  侧壁＋底影）；图例按 §7.8 布局，无缺键、无乱码。可测 proxy：
  键帽侧壁可见高度 ≥2px，顶面与侧壁亮度差 ΔL ≥0.05。截图量测＋用户目视。
- 门五（盖）：木纹＋柔光＋螺丝（井区 4 颗＋钢板四角 4 颗，共 8 颗），
  盖子连续无接缝。可测 proxy：木纹贴片可见、螺丝 8 颗齐全。用户目视。
- 门六（功能融盖）：功能行／字体条／候选栏落在盖子上（键帽／刻字金属牌／
  候选纸条），无独立 UI 条。用户目视。
- 门七（功能全通）：§8 映射表每行功能点按可用（打字、删除、换行、空格、
  退行、换纸、进纸、拨杆、字体、候选、语言、成就、导出、音效、标题）。
  真机点按验真。
- 门八（底层逻辑零改动）：对照 §9.4 底层文件清单做 `git diff --stat`，
  清单内文件零改动；清单外文件不得以"顺手"为由改动。
- 门九（三端）：直板机／平板／折叠半开三端同一套零件语言，渲染质量同档；
  折叠外屏紧凑布局功能同等可达。用户目视。
