## 1. 相对总纲的增量（含评审 resolve）

1. **F16 判定（B-1 resolve，按总纲字面）**：现有 `export_preview` 只含纸面图＋正文（ExportPage.ets），**不含机器框**——按总纲"若快照对象含机器框则为渲染变体，否则另做离屏渲染"，本批**另做离屏渲染**：`ExportTemplate` 由 `UIContext.getComponentSnapshot().createFromBuilder(builder, delay, checkImageStatus)` 直接渲染为 1080×1440 PixelMap，不挂可见节点、不依赖导出页布局；导出进度浮层只显示进度与状态，不承载模板。若 `createFromBuilder` 在 API 12 不可用（设备未验），fallback：沿用 `export_preview` 快照（无机器框）并在批报告记缺口，不崩溃。
2. **服务边界（B-2 resolve）**：
   * `services/ExportService.ets`：**纯字节构建**，签名
     `buildTxt(docId): ExportResult{ok,bytes,error}`
     `buildPdf(ui: UIContext, docId, machineKind): ExportResult`
     `buildPng(ui: UIContext, docId, machineKind): Promise<ExportResult>`（内部 `createFromBuilder` 调 ExportTemplate）
     `buildPngFromPreview(ui: UIContext, nodeId): Promise<ExportResult>`（F4 阶段的现有快照路径；F16 后默认走模板）
   * `FileHelper.saveBytes` 只负责"用户选位置＋写入"，返回 `SaveResult{status:'ok'|'cancel'|'error', uri, error}`（本批 Modify FileHelper，见 M-10）。
   * 分享文件落 `filesDir/export-tmp/`，分享调起后保留到页面 `aboutToDisappear` 清理；"已保存"只在用户选位置成功后出现；仅分享路径文案是"已调起分享"。
   * 进度/状态 `@State` 归 ExportPage；busy 时 `onBack` 先取消/忽略。
3. **F4 反馈（M-4/M-5 resolve）**：导出页内常驻结果态（不靠 HintBar）：`idle→building→saving→sharing→result`；分享面板调起后**不淡出**，常驻"已保存，已调起分享"直到用户离开页面；失败显示原文错误。文案禁止"已分享成功"。
4. **导出前 flush（M-6 resolve）**：ExportPage `aboutToAppear` 不导出；每次保存/分享前调 Index 传入的 `onBeforeExport()`（Index 内 `flushSave()` 并返回是否空文档）；空文档禁用按钮＋空态"这张纸还没有字"。
5. **PDF 信纸头（M-3 resolve）**：PDF 首页顶部画"机器名＋文档标题＋日期＋页码"文字抬头；**双细线不画**（pdfService 当前只用 addTextObject，无画线 API 实证），纸种/边距/色带/字体不进入 PDF；批报告记"与界面信纸头口径部分不符"。
6. **PDF 中文（M-2 resolve）**：不宣称"已验证中文可出"；沿用现有 pdfService 文本路径，设备未验记 UNVERIFIED；失败时明确报错。
7. **导出页引导（M-8 resolve）**：第 1 批已写 `guide_export_*`（当时与总纲"第 3 批再定"冲突，批报告记录）；本批只**复核文案值**并按 F4 实际按钮改 `guide_export_2`（"可以只保存到本地，也可以直接分享"），不新增键。
8. **分享指引（M-15 resolve）**：导出页常驻说明行（`guide_export_hint` 已有）＋首次进入导出页的 3 条引导中第 3 条改为"分享只调起系统面板，不保证对方已收到"（键不变，值更新）。不新增 `share_*` 键。
9. **事件计数（M-11 resolve）**：保存成功→`StatsService.recordEvent(DOC_SAVED)`；分享调起成功→`recordEvent(DOC_EXPORTED)`；不重复计数（每次用户操作一次）。
10. **反馈动效 token（M-13 resolve）**：新增 `model/ExportCore.ets` 常量：`EXPORT_PROGRESS_MIN_MS=300`、`EXPORT_RESULT_FADE_MS=0`（不淡出）、文件名前缀 `export-`；`docs/界面重设计稿.md` §1.1.1 补 D7（分享反馈：进度条 300ms 最少展示、结果常驻），§6.2 更新为双按钮。
11. **文件名（M-10）**：`ExportCore.safeFileName(title, ext, ts)`：去非法字符 `\\/:*?"<>|`、空标题回落 `回车`、拼 `回车-<title>-<yyyyMMdd-HHmmss>.<ext>`；DocumentSaveOptions 用 `fileSuffixChoices: ['<描述>|.'+ext]`，不用 MIME。
12. **开关（M-14）**：本批不新增 prefs 开关（F4 是导出页既有功能补全，无半成品窗口；与第 2 批开关策略不同，理由写入批报告）。
