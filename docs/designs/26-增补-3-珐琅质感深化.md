## §1 盖面：从"纯色"到"一块材料"（binding，主项）

纯色＋线性渐变不够。珐琅／喷塑金属的"材料感"来自三样东西，本批三样都要有，
缺一样都算没做完：

### 1a. 径向光泽（取代线性渐变）
- 盖面光泽改为**径向**（不是线性）：高光中心在盖面上部中央（约 x 181vp、y 180vp，
  即纸与字篮之间的盖面空白处），向四周柔和衰减；中心比 token 亮约 5%（L+0.05），
  四角比 token 暗约 4%（L−0.04），总量 ΔL ≤ 0.09。
- 径向光泽让人眼读出"曲面／厚度"，线性渐变只能读出"上下明暗"。这是最关键的一点：
  同样 ΔL，径向看起来像一块有弧度的盖子，线性看起来像一张纸。
- 验收：盖面取样，中心亮、四角暗，呈径向分布（不是上下线性分布）；均值与 token 误差仍 ≤2。

### 1b. 边缘倒角线（给盖子"厚度"）
- 盖面四周加一条 1–2px 的浅色倒角线（比 token 亮约 8%，L+0.08），沿盖面边缘走一圈，
  只在盖面与屏幕边缘／与黑色件（键盘井、字篮井口）交界处可见。
- 倒角线是"这是一块有厚度的板子"的信号，没有它，盖面和屏幕边缘糊在一起。
- 验收：V=0 整机照里，盖面边缘有一圈极细的浅色线（不要粗、不要亮到刺眼）。

### 1c. 零件在盖面上的软阴影（让零件"长"在盖面上）
- 纸、滚筒、字篮扇底座、键盘井——这四件压在盖面上的零件，各自在盖面上投一条**软阴影**：
  阴影为黑色、透明度 0.12–0.18、模糊半径 6–10px、向下方偏移 2–4px。
  阴影只出现在零件与盖面的交界处，不要满铺。
- 没有软阴影，零件像"贴"在盖面上；有了软阴影，零件像"放"在盖面上，
  盖面立刻有了"表面"的感觉。这是原版参考图里最容易被忽略、但最决定"产品感"的一点。
- 验收：纸下沿、滚筒下沿、扇底座下沿、键盘井上沿各有一条柔和的阴影带
  （不要硬黑边、不要生硬的描边）。

### 1d. 不做什么
- **不要**加木纹、颗粒、噪点、斑驳——盖面仍是光滑珐琅，微纹理不在本批做
  （批 37 复核里提过的"微纹理"是备选，本批先用光泽＋倒角＋阴影三样，够用了；
  若三样做完仍显平，再议微纹理）。
- 渐变总量仍 ≤0.09，均值与 token 误差仍 ≤2（沿用增补-2 的量测口径）。

## §2 字篮井去黑（binding，最大视觉改动）

- 井底由黑改成**与盖面同色薄荷绿**（四机各用各机的盖 token）。
  扇（银杆）直接长在机身上，同原版图 2。
- 井口曲线保留为一条**细的阴影线**（深色、1–2px、透明度约 0.5），不是一大片黑。
  井口曲线是"井"的边界线，不是"井底"。
- 枢轴、扇底座保留，颜色不变。扇图仍用 `basket-fan-3d-v2.png`。
- 验收：字篮特写里扇底为薄荷绿、扇杆银亮、井口曲线为细阴影线；
  整机照里字篮区不再有大黑半圆。

## §3 顶栏去黑（binding）

- 顶栏底（0–56vp）由深棕黑改成**与盖面同色薄荷绿**（四机各用各机的盖 token）。
- 边铃（金）、铭牌（金）、返回拨杆（银杆＋金球）压在薄荷绿上，
  金／银在浅底上对比足够，不用改零件色。
- 顶栏与盖面同色后，机身薄荷绿从顶一直通到底（除键盘井），整机成为一块完整的薄荷绿。
- 验收：V=0 整机照里顶栏与盖面同色、无深色横条；边铃、铭牌、返回拨杆清晰可辨。

## §5 验收：完整效果（binding）

本批验收只认"一眼可见"，不认"数值上改了但看不出来"：

  （顶栏＋字篮井去黑是主要贡献；键盘井仍黑，占比不会到 0）。
- **盖面材料感**：盖面取样呈径向分布（中心亮、四角暗），不是上下线性；
  边缘倒角线可见；四件零件的软阴影带可见。
  三样缺一样都算任务 1 未完成。
- **字篮井**：特写里扇底为薄荷绿、井口为细阴影线、无大黑半圆。
