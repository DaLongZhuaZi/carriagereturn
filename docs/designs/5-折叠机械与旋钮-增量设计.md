## 1. 相对总纲的增量（含评审 resolve）

1. **F7 移出本轮（B-1 resolve，按探针 fallback）**：`probe_fold_angle.py` 的 fallback 写明"仍无模拟器则 F7 移出本轮（报告记）"。本机无折叠设备、无 hvigor/SDK、DevEco 模拟器无启动入口，且 ArkTS 成员名编译期解析（try/catch 兜不住编译错），无法自证 API 形态。**本批不交付 F7 代码**（不建 FoldService、不改布局）；批报告写"F7 跳过：Q3 缺省不可执行（无模拟器），待有设备/模拟器补"，第 7 批真机冒烟仍列为延期项。
2. **F12 挂起，不关闭（B-3 resolve）**：本机无设备数据，不满足总纲"打点数据显示不出 8–11 秒"的关闭条件。**本批不改换纸时长/时序**；`PAPER_CHANGE_TRACE` 保持编译期常量 false（仓内无运行时开关，不开）；批报告写"未复现（无数据），保留打点，F12 挂到有设备/第 7 批"，不写"关闭 F12"。
3. **F13 旋钮恢复（M-2/M-8 resolve）**：
   * 门控 `custom.knob.enabled`（prefs，**默认 off**；移除点＝基线重拍批准后第 7 批）。默认关时**不渲染**，1920s 门图像素不变。
   * 视觉：`components/KnobLayer.ets` 左右两枚 `knob.png`＋**金色指针细线**（2vp，从圆心到边缘，随角度转）——旋转可见；尺寸 = `Pw×0.17×0.92`（与 CarriageLayers knobD 同源）；左 x = paperLeft−knobD−4，右 x = paperLeft+Pw+4，中心 y = carriageTop；`.hitTestBehavior(HitTestMode.None)`，**不是触摸目标**；zIndex 3（纸前、拨杆触摸层 zIndex20 之下）。
   * 挂载：仅 `machineKind===1920s && hasLayers() && useLayers && knobEnabled`；knob.png 仍在 `detectLayers` need 列表（缺失→整层回退，KnobLayer 同条件不挂载，符合现状）；本批不扩展 detectLayers 按机型探测，记已知限制。
   * 门图：默认 off → H7 门不变（静态可证）；若用户在基线重拍仪式后开启，则车架左/右区会有预期差异（旋钮），必须按 AGENTS 基线更新仪式处理。
4. **F14 过渡复核（B-4 resolve）**：核实 `applyMachine` 会调 `measureStage()` 重算几何（不只 fadeSwitch）；因此总纲"过渡与几何相关则第 5 批重验"成立，但**无设备无法验"同帧不闪/不跳"**。本批只做静态断言：`fadeSwitch()` 函数体不含几何写入；重验项记"未验（缺口：主观流畅感）"，第 7 批冒烟。
5. **引导锚点复核（M-1 resolve）**：核实**现有引导没有 anchor 生产者**（GuideCore 只有 page id/资源键；Index 打字机 steps 纯文本；GuideOverlay 的 anchor prop 未被任何页面传值）。批报告如实写"锚点体系未落地，F7 移出后无折叠几何可复核"；H5 只断言 page id/Index 映射完整（13 页），不冒充"锚点已对齐"。
6. **界面稿（M-6 resolve）**：不改 §2.4 三态口径、不改 §2.1/§2.5；只在界面稿补"F13 旋钮门控/外观/门图仪式"与"F7/F12 本批状态"，不重写折叠三态。
7. **测试文件（M-5 resolve）**：`knob-static.test.mjs`、`paper-change-static.test.mjs`、`f14-static.test.mjs`、`guide-anchor-static.test.mjs`（后两项可合并为 `batch5-static.test.mjs`，本设计按四文件写）。
8. **N-1/N-2 随 F7 移出作废**：不建 FoldService，无 foldStatus/foldHalf 双状态。
