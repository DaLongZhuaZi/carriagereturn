## §1 材质：木纹照片 → 光滑珐琅（binding）

- **盖面不再是图片**。删除木纹贴片的渲染，盖面改为 ArkUI 纯色＋极轻的纵向清漆渐变
  （只做光泽，不做纹理）：顶部比 token 亮约 4%（L+0.04），底部比 token 暗约 4%（L−0.04），
  中间线性过渡，**不许出现任何纹理、颗粒、斑驳、木纹线**。
- 清漆光泽是"材料本身的光"，不是"画出来的明暗"：渐变幅度要小（总 ΔL ≤ 0.08），
  绝不许用 4 停强渐变（那是批 36 的做法，已证实会把均值推离 token、看起来像贴纸）。
- 盖面均值必须等于 token（量测方法见增补稿 §5.6：盖面取样均值与 token 误差 ≤2，
  本批沿用，柔光不再单独微调——渐变幅度小，均值自然贴合）。
- 螺丝 8 颗保留（位置不变），嵌在光滑盖面上；螺丝本身是金属小圆点，不要改。

## §2 新 token：薄荷绿系光滑珐琅（binding）

  不再是四机各一色。键帽哑光化：去掉 3D 生成帽身的强高光，帽面平、边缘柔、阴影软。

## §3 同步的三件小事（binding）

1. **纸改白**：纸 token `#eee4ce` → `#faf8f2`（见 §2）。卷曲图 `paper-curl-v2.png` 是按旧米色画的，
   若与新纸色不协调，改用 B 档压暗带（12vp／透明度 0.35）兜底，不要为迁就旧卷曲图改纸色。
2. **键帽哑光化**：帽身高光减弱（生成帽身重出或调参，目标：帽面无硬高光点，边缘柔和），
   图例字号不变、颜色不变。键盘井不变。
3. **扇图提亮**：`basket-fan-3d.png` 偏深偏重，在新浅底上仍发暗——用 PIL 提亮（亮度 +25%、对比 −15%），
   或重生成一张更轻、更亮的扇图（细银杆、透光感）。字模仍接受"显示尺寸下不可辨"的现状。
