> 承接用户 2026-11-22 01:01 令：A 和 B 都要做；老机型素材里的“故意做旧”去掉，改成自然的使用痕迹；素材由沙箱生成。

## 0. 背景：矛盾的根（已核，HEAD `18d816a`）

- 收藏＝4 台老机（`MachineKind`：1920s-upright／1930s-portable／1950s-streamlined／1960s-electric），每台有照片、品相、解锁、`MachineCatalog` 全套 spec。
- 打字机＝1 套现代“26”组合：扇 `basketFanImage` 平板永远 `v5-wide-26`、手机永远 `v4`（四台同图）；盖只有 `lid-sheen-v2.png`（`lidTileImage()` 是 0 调用点死代码）；键帽 `KeyGrid` 已按 `slug()` 分机型（`cap3d-<era>-matte.png`／`cap3d-space-<era>.png`），是少数已接线的；颜色只有 `lidColor` 经 `tierToken` base，且 base 四台全是薄荷绿系（批 37 决定，不动）。
- 所以选哪台老机，打字机基本不变；收藏承诺的 4 台老机与实际打字机是两张皮。

## 2. 接线（A）：四台老机成为真打字主题

### 2.1 扇 `basketFanImage(machine, wide)`（`Parts26.ets`）

- `wide == true`（平板）：按 `machine` 返回本批宽扇——1920s→`basket-fan-3d-v5-wide-1920s.png`，1930s→`…-1930s.png`，1950s→`…-1950s.png`，1960s→`…-1960s.png`；现代机（§3）→沿用 `basket-fan-3d-v5-wide-26.png`。
- `wide == false`（手机）：四分支不再全用 `v4`，改用已在仓的年代扇——1920s→`basket-fan-1920s.png`（1864×1091），1930s→`basket-fan-1930s.png`，1950s→`basket-fan-1950s.png`，1960s→`basket-fan-1960s.png`；现代机→`basket-fan-3d-v4.png`。
- 其余不变：`ImageFit.Contain`、盒比 2.6（平板）／1.69（手机）与图比一致（误差 ≤1%），不拉伸。

### 2.2 键帽（已接线，核验即可）

- `KeyGrid.slug()` 取 `machineKind` 的 `-` 前缀；`cap3dRawfile()`→`cap3d-<slug>-matte.png`，空格→`cap3d-space-<slug>.png`，静态分支→`cap3d-<slug>.png`。四台老机文件均已在仓，**不改代码**，只核验：切到每台机，键帽确为该年代图（不是全用同一张）。
- 现代机 `slug() == '2020s'`，取本批 §1.2 三张（§3 接线时加分支，见 §3.2）。

### 2.3 盖与颜色（不动）

- 盖：继续 `lid-sheen-v2.png`（渐变柔光层，全机共用；Fill 例外仍待用户裁决，见批 65 遗留，不在本批改）。
- 机身色：继续 `tierToken(machine, 'base')`（四台均为薄荷绿系，批 37 决定）。**本真年代色（1920s 深色／1930s 深棕／1950s 奶油／1960s 灰）本次不改**，用户未定；年代区分由扇＋键帽＋照片承担。若用户日后要本真色，另立批改 `TIER_TOKENS` 的 base 列。
- 其余四档色（paperwell／keybed／steel）已按机型取 `tierToken`，不改。
