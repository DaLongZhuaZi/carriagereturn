## 1. 相对总纲的增量（含评审 resolve）

1. **Q6 父 agent 代决（B-7 resolve）**：Q6 已批准缺省为 Freesound 采制，但本机**无网络、无 Freesound 凭据**，采制在批内不可完成。父 agent 代决采用 Q6 原文备选 **B：复用现有 23 个 OGG 重组／确定性 DSP 变体**；记录在批报告，用户可复核与回滚（若要求 Freesound，替换 `sound/pack-*` 即可，代码不变）。每包 `SOURCE.txt` 复制上游来源/协议段并记录 ffmpeg 版本、滤镜链、日期、SHA-256；致谢页列上游作者（不低于现有 `sound/pack/SOURCE.txt` 的 CC BY 署名要求）。
2. **F11 统计行迁移（B-1 resolve）**：`HomePage.refresh()` 删除自算总字数与连续天数，改调 `statsService.totalWords()`／`statsService.consecutiveDays()`；`latestId/latestTitle` 仍从文档列表单独取。**唯一派生层**。
3. **F11 今日字数（B-2 resolve）**：落字热路径只做内存自增（`StatsService.recordChar()`，不写盘）；`StatsService.todayChars()`＝prefs 已落盘值＋内存 pending（跨日归零）；`flushPending()` 在**离页/切页/导出前/应用退出**时批量写一次（非 800ms 自动保存）。删除字不扣减。纯逻辑抽 `StatsCore.mergeDailyChars(prevKey, prevChars, todayKey, delta)` 单测。
4. **F11 刷新时机（M-7 resolve）**：Index 持 `@State statsRev`，在设置页改目标、从卷宗/设置返回主页、导出保存后递增；HomePage `@Prop statsRev`＋`@Watch` 重取；目标行**空文档也显示**"今日 0 / 目标 500 字"（N-3 resolve）。
5. **F11 目标回显（N-1 resolve）**：SettingsRow `slider` 模式在滑杆左侧/下方显示 `sliderValueText`（如"500 字"）；每日目标 100–2000 步进 100。
6. **F14 锁定卡可见进度（B-4 resolve）**：进度不放在"只有解锁才能进"的详情页，而是 `CollectionPage` 锁定卡片上显示"当前总字数／连续天数"；详情页也显示同样进度。`unlocked()` 本批仍临时 true（Q2 未决），F5 落地后锁定卡仍可看进度。
7. **F14 阈值文案（B-3 resolve）**：Q2 未决期间 `machine_cond_*`（3 条）与详情页条件统一改为"待定（阈值待批准）"，**不显示 5000 字/7 天/3 次等数字**；G3 静态断言 `machine_cond_*` 不含数字阈值。F14 只显示非阈值事实：`totalWords()`、`consecutiveDays()`、`paperKindsUsed()`（新增，见 8）。
8. **F14 纸张种类数据源（M-5 resolve）**：`StatsService` 新增 `paperKindsUsed(): number`，数据源 prefs `stats.paper.kinds`（逗号集合，`applyPaper` 成功时写入）；`StatsCore.paperKindsMerge(prev, kind)` 纯函数单测。F14 文案是"用过 N 种纸（当前统计）"，不冒充累计成就进度。
9. **F14 过渡动效（M-6 resolve）**：沿用 `applyMachine` 现有 `fadeSwitch()`（只改 `switchFade` 透明度、不碰几何）；G3 增加静态断言"applyMachine 不写 paperWidth/paperHeight/carriageHeight 等几何"，与第 5 批重验口径一致。
10. **F8 独立包与命名（M-1 resolve）**：四包目录 `sound/pack`（1920s）、`pack-1930`、`pack-1950`、`pack-1960`；**每包内部文件名保持无前缀**（`key-01.ogg`…），与 `audio-verify` 的 ROLE_CHECKS 一致；`fallbackStems()` 对非默认包改为无前缀列表；`pack2-key-*` 不作为独立包、生成脚本排除（避免无用变体与哈希重复）。`playKeyTransient`／`BACKSPACE_FALLBACK_STEM` 依赖 `key-transient`／`key-11`，每包必须包含。
11. **F8 切包不静音（B-5/M-12 resolve）**：`AudioService` 采用**双缓冲 preload**：新包先加载到独立 SoundPool/Banks，全部成功后再原子替换并释放旧池；加载期间旧包可继续播放；并发用 `preloadGeneration` 校验，旧的过期请求丢弃。失败保留旧包并 hilog。
12. **F8 启动唯一入口（B-6 resolve）**：删除 `Index.aboutToAppear` 末尾的 `preload('pack')`，`applyMachine` 按 `packForMachine` 唯一选包；G5 静态断言 Index 只有一处 `audioService.preload(` 且参数来自 `packForMachine`。
13. **F8 选择层证据（M-2 resolve）**：`AudioEmitTrace` 增加 `pack` 字段；`AudioService.emit` 传 `this.packName + '/' + stem`；`AudioTrace.ets` 列入文件清单；G5 拆"静态映射可证／运行时 pack 记录未验（无设备）"。
14. **F8 阈值（M-3 resolve）**：DSP 参数实测标定：pitch ±15%／1960 +20% + treble +6dB、volume 0.72、`alimiter=0.95`；`audio-verify` 全量跑实测跨包同角色最小距离 **0.0469 ≥ 0.03**（记录于批报告）；R1 改为此组参数，不再写"±3%"。
15. **事件语义（M-13 resolve）**：导出保存/分享都记 `DOC_EXPORTED`（F5 依赖"导出分享 3 次"）；`DOC_SAVED` 本批不用于 800ms 自动保存（避免计数膨胀），留给第 6 批文档显式保存事件；批报告记录第 3 批把 DOC_SAVED 接在导出保存的语义错误并修正。
16. **确定性（N-4 resolve）**：`make-sound-packs.py` 固定 `-map_metadata -1 -c:a libvorbis -q:a 4`，SOURCE 记录 `ffmpeg -version` 首行；`--force` 重跑得到相同字节（同版本）。
17. **本批引导**：不新增 GuideCore 页 id；主页/收藏详情新增行复用现有 `guide_home_hint`／`guide_collection_detail_hint` 常驻行，不新增第 4 条（N-4/M-9 resolve）。
