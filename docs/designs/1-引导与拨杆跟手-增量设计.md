## 1. 相对总纲的增量（含评审 resolve 后的定案）

1. **单一挂载点（B-2 resolve）**：引导浮层**只在 Index 挂一个实例**（根 Stack 最上层）。10 个页面文件各自 `export function guideStepsFor<Page>(): GuideStep[]`（文案与功能同处一源，用字面 `$r('app.string.guide_<page>_<n>')`），Index 维护 page id→函数映射；**页面不持有 guideVisible**，避免两套事实源。打字机页在 `syncFromStack()` 检测 `top==='typewriter'` 时判定，不用 aboutToAppear（B-2）。
2. **GuideOverlay 保持 props-only（B-1 resolve）**：新增 `model/GuideCore.ets`（纯函数：11 个 page id 清单、`pageKey(page,n)`、`allPageKeys()`、`onboardingKeys()`、每页期望条数、`isValidPage`）与 `services/GuideService.ets`（seen 读写、resetPages、resetOnboarding、enabled）。GuideOverlay 只加 `GuideStep.text: ResourceStr`（**显式声明修改第 0 批契约**，同步 `check-contracts.py`）与按钮资源键（B-3）。
3. **首启序列（M-2 resolve）**：启动引导优先；`onboardingVisible=true` 期间所有页面引导不显示、不置 seen；关闭启动引导后，若当前页未看过则显示一次页面引导；`ONBOARDING_SEEN` 置位在关闭/跳过时。
4. **重播（M-3 resolve）**：SettingsPage 加两行（`SettingsRow` link 形态）——"重播页面引导"（`GuideService.resetPages()` 清 11 个 `guide.<page>.seen`，HintBar 提示"已重置，下次进入页面生效"）、"重播启动引导"（`ONBOARDING_SEEN=false`，立即显示启动引导）。保留 `ONBOARDING_SEEN` 不被 resetPages 改动。
5. **常驻说明行（M-9 resolve）**：`PageShell` 增加 `subtitle: ResourceStr = ''`，显示在标题下方（12vp，灰 0.6），9 个 PageShell 页各传 `guide_<page>_hint`；HomePage 已有静态引导语（充当常驻行）；打字机页不加（总纲）。文案键：11 页 hint 键。
6. **引导开关与测试模式（B-5/M-11 resolve）**：产品开关 `guide.enabled`（prefs，默认 **on**——F1 批内一次交付完整，无半成品窗口；移除点＝第 7 批）。测试模式不放 TestHooks 的 `enabled()`：新增 `guide.testMode` prefs（仅测试构建可由脚本置 true）；验证模式＝testMode true（seen 可复位、可关闭引导），回归模式＝false（引导不显示）。**发布构建无复位入口；无构建变体是已知缺口（运行时不可达，代码仍在，第 7 批补）**，批报告如实写。
7. **F9 目标函数体写死（B-4 resolve）**：
   ```
   onDragRatio(): void {
     if (this.dragRatio <= 0.001) {
       this.getUIContext().animateTo({ duration: 150, curve: Curve.FastOutSlowIn }, () => {
         this.angle = this.restDeg;
       });
       return;
     }
     this.angle = angleFor(this.restDeg, this.swingDeg, this.dragRatio);
   }
   ```
   四份文件同形；同时把 `onTickChanged` 的跳过条件从 `this.dragging` 改为 `this.dragRatio > 0.001`（拖拽中不抢角，松手后 tick 正常摆动；M-8）。
8. **删除局部手势（M-6 resolve）**：四份 LeverLayer 的 `Image.onClick` 与 `PanGesture` 删除（Index 总成层是唯一生产者；保留双路径有双换行风险）。`onLeverTap` prop 保留以兼容 Index 传参（不再有调用点，第 7 批清）；`dragging` 仅保留给 onTickChanged 历史兼容（改为 ratio 判定后无用，可一并删）。
9. **浮层动画（N-3 resolve）**：浮层瞬时显示/消失，无动画；不新增动画验收。
10. **文案键规格（M-10 resolve）**：page id 固定 11 个：`home／dossier／dossier_detail／document_view／collection／collection_detail／customize／settings／export／pinyin_settings／typewriter`；每页 `guide_<page>_1..n`（n=2–4）＋`guide_<page>_hint`；启动 `guide_onboarding_1..4`；按钮 `guide_btn_skip`／`guide_btn_ok`。`GuideCore.stepsExpected()` 固定每页条数，`guide-keys.test.mjs` 用显式清单断言（不反推）。
