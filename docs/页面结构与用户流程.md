# 回车 CarriageReturn · 页面结构与用户流程

> 状态：设计提案（2026-11-03）。依据：产品定义稿 v3.3、核心打字体验调研报告。
> 已定项（定义稿 v3.3）：美术 ＞ 功能；完全离线；现阶段免费无内购；收藏全部虚构时代机（Hanx 式做法）；文档只存本地；不做账号、云同步、应用内社交。
> 本稿中标注“提案，待用户点头”的事项均未定；未验证事项标注“待真机验证（定义稿 §8.1）”。

## 1. 屏与入口

应用共 5 个屏，主屏为打字机，其余 4 个为入口屏：

| 屏 | 内容 | 入口位置 |
|---|---|---|
| 主屏（打字机） | 纸面（上）加机械键盘（下）；当前机器、纸张、色带、字体状态 | 应用打开即主屏 |
| 收藏（机器图鉴） | 已解锁机器列表、未解锁机器锁定态、每台机器的史实介绍文字与成就入口 | 主屏入口 |
| 纸张色带 | 纸张选择（信纸、稿纸、明信片、便签）、色带选择（黑、蓝、红）、字体选择 | 主屏入口 |
| 文档库 | 本地文档列表：打开、重命名、删除；新建文档 | 主屏入口 |
| 设置 | 音量、震动、叮声、修正方式、默认纸张、默认机器；关于页；音效致谢页（提案，见 §6） | 主屏入口 |

- 入口原则：任何入口屏返回主屏后，打字状态（文档、光标、纸张滚动位置）全部保留，不重建编辑器。
- 界面文案走资源文件，不硬编码在渲染逻辑里（仓库 AGENTS.md）。
- 折叠屏三态下的页面结构（定义稿 §6）：半开上纸下键；展开时文档库与机器收藏可走双栏；外屏只做快速便签加文档列表单栏。三态切换只换布局参数，不重建编辑器组件实例。

## 2. 首跑流程（打开即打）

首屏标准（定义稿 v3.3）：打开即一台美机加一张纸加一句引导，3 秒内能敲出第一声。

1. 首次打开：直接进入主屏，不设开屏广告、不设长流程新手教程。
2. 默认配置（提案，待用户点头）：默认机为 1920s 直立式座机，默认纸为信纸，默认色带为黑色，默认字体为英文 Courier Prime（中文宋体全量待选）。
3. 一句引导：纸面上方或纸面顶端显示一句引导（文案走资源文件，具体文案待定），引导用户敲下第一个键；引导在用户第一次落字后消失，不再重复出现。
4. 第一声：用户敲下第一个键即触发按键音加键下沉动画加落字（声音在 TouchType.Down 当刻触发，不等 Up；SoundPool 重叠行为待真机验证，定义稿 §8.1 第 4 项）。

## 3. 空状态

- 文档库空：首次进入文档库时无文档，显示空状态引导（文案走资源文件）：提示返回主屏开始打第一篇，不设示例文档、不预置他人内容。
- 收藏未解锁锁定态（提案，待用户点头）：未解锁机器显示锁定态与解锁条件，不提前展示完整机器图；已解锁机器显示完整机器图与史实介绍文字；锁定态不透露未解锁机器的完整外观（避免剧透，也符合版权安全线：未定稿机器不提前曝光）。
- 纸张色带空状态：不适用——首发纸张、色带、字体均为内置默认项，无空状态；用户导入的自定义纸张与字体出现在同一列表的“我的导入”分组，导入失败时提示格式不支持（图片 png/jpg/webp；字体 ttf/otf）。

## 4. 核心流程一：打字 → 导出 → 系统分享

1. 打字：主屏敲击落字；英文走自绘 QWERTY 键盘，中文走系统输入法 attach（双通道为调研推荐方案，提案，待用户点头，见 §7）。
2. 导出：主屏或文档库进入导出，选择格式：信纸图片（所见即所得）、PDF（多页文档）、纯文本（内容可再编辑）。
   - 图片导出：`componentSnapshot.createFromBuilder` 离屏渲染，截图放在点击事件里（不放在构建期，否则截到上一帧）；长图分段拼接并限制总高度防内存爆炸（上限待真机验证，定义稿 §8.1 第 8 项）。
   - PDF 导出：A 路 PDF Kit 文本路径为主，B 路 Webview createPdf 为兜底；自定义字体能否嵌入待真机验证（定义稿 §8.1 第 6 项），若不行退回图片贴页方式；PDF Kit 手机可用性待真机验证（定义稿 §8.1 第 1 项）。
3. 系统分享：Share Kit 拉起系统分享面板；分享记录的 uri 必须是 `fileUri.getUriFromPath(沙箱路径)` 转出的 file:// URI（裸沙箱路径会被拒收且 Promise 照常 resolve，应用层零感知）；缩略图限制 32KB 以下；PDF 的 UTD 串需实测确认，不硬编码猜测（待真机验证，定义稿 §8.1 第 7 项）。
4. 不加水印（产出物干净才值得晒）；落款与日期印章可选（用户自选）；分享走系统分享，不做应用内广场、社交、评论。

## 5. 核心流程二：换机 / 换纸 / 换字体 / 换色带

1. 入口：主屏进入收藏（换机）或纸张色带（换纸、换字体、换色带）。
2. 即时生效：切换后主屏纸面与键盘立即换装，不重启、不重建编辑器；换机同时换音效包、字体、键程手感与纸面适配（行距、边距）。
3. 元数据记录：换机、换纸、换色带、换字体均写入当前文档元数据（见技术架构设计）；同一文档内换装不影响已有落字，已落字保留换装前的纸张、色带、字体呈现。
4. 句中换色带：打字过程中可换色带，新落字用新墨色，旧字不变；墨色以段为单位换 `fontColor`，成本最低。
5. 自定义导入：纸张加字体为首发导入范围（已定）；音效包导入放二期（已定）；导入走 FilePicker 选文件后拷入沙箱并校验格式，导入内容只存本地，不上传；应用内提示“请确保你有权使用该字体”。

## 6. 核心流程三：成就解锁 → 收藏新机

1. 成就达成：打字行为累计达成成就条件（成就体系见成就体系设计稿，全文为提案，待用户点头）。
2. 解锁提示：主屏或收藏页弹出解锁提示（文案走资源文件），提示新机器名称（时代加结构命名，不用品牌名）与解锁条件已达成。
3. 新机入收藏：新机器进入收藏页已解锁列表，可立即切换使用；切换后音效包、字体、键程手感与纸面适配随新机变化。
4. 史实介绍：每台收藏机配一段史实文字（年代、结构特点、历史地位），文字原创、不抄现有资料；史实文字只放成就、图鉴介绍页纯文字加无关联声明，不进机器名、商店截图、图标、启动页。

## 7. 核心流程四：设置 → 关于 → 音效致谢（提案，待用户点头）

1. 设置：音量、震动、叮声、修正方式、默认纸张、默认机器；零遥测说明常驻设置页。
2. 关于页：应用介绍、离线声明（不联网、不上传、不做 AI 写作）、版本信息。
3. 音效致谢页（提案，待用户点头，定义稿 §8 第 7 项）：若采用 CC BY 第二梯队素材（ddohler、YleArkisto）或 ZapSplat 素材，则致谢页必需；全 CC0 加实录则可不设。致谢页承载全部 CC BY 与 ZapSplat（如采用）致谢，署名行用各文件页提供的署名文本生成，不手写改写作者名与标题。
4. 中文输入切换（提案，待用户点头，定义稿 §8 第 1 项）：英文自绘 QWERTY 与中文系统输入法用一个切换键切换；系统输入法弹出时纸面相应上移（键盘避让）；折叠切换时不 detach/re-attach 输入法（attach 只跟随焦点变化），否则中文输入会断。拼音预编辑第三方输入法兼容性（`setPreviewText` 是否都发该事件）待真机验证（定义稿 §8.1 第 2 项）；`updateCursor` 坐标空间待真机验证（定义稿 §8.1 第 3 项）。

- 默认机（1920s 直立式座机）与默认纸（信纸）为提案，待用户点头。
- 收藏未解锁锁定态的展示方式（锁定态加解锁条件，不提前展示完整机器图）为提案，待用户点头。
- 音效致谢页是否设，待用户点头（定义稿 §8 第 7 项）；若采用 CC BY 素材则致谢页必需。
