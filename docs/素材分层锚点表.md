## 代码批落位决策（§2.8，2026-11-04 晚定，与本表配套）

- 滚筒裁切：源图 3200×502 纵向居中裁至 7.14（3200×448，上下各裁 27px），再按宽画布 (舞台宽+最大行程) × Hc 放，Hc = (舞台宽+最大行程)/7.14；不许拉伸、不许走 alpha。
- 容器与四层落位、纸面光标改名、回退规则、验收，全部见 `docs/界面重设计稿.md` §2.8；本表锚点（像素 + 比例）是 §2.8 落位公式的输入，不是另一套口径。
- 纸面光标与中央件不许对齐：纸面光标画在纸上（文档坐标）、中央件画在字车上（机器坐标），两者分属不同图层；验收不以对齐为过，以“字车条上无细线、四层同进同退”为过。

## 处理记录（去底方法与坑）

- 白底去底：白底图用 min(r,g,b) 阈值去底（≥245 透明、≤200 不透明、中间线性羽化），不用 rembg——白底 + 深色件时此法比 rembg 稳，且细杆（压纸卷杆、字杆）不会被缩图吃掉。
- 阴影：生成图自带地面阴影，去底后会残留灰色晕。中央件：实心金属止于 y=1342，裁至 1342（不再留边）；压纸卷：y>90 时只保留两辊 x 段（678–887、1917–2124，扩 10px），其余 x 置透明，并裁至辊底 y=182；两层底部残留的 1–2px 浅色边是金属底边高光，不是阴影，保留。
- 滚筒：第一版误用 alpha 去底，滚筒顶部高光近白被当白底抠掉、在深底上成深灰斑——滚筒是矩形纹理带，不是抠形件，改存不透明 JPG 全幅裁带（y 421–922，高 502px），不得再走 alpha 路径。
- 中央件窗：白底去底后窗自然成透明孔，纸面透过窗可见，属正确物理结构，不得把窗填白。
- 键区：不在本层文件夹，见 1920s keymap（母版 v2、带 phone/fold，43 帽，坐标未变）。
