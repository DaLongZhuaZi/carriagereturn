## 1. 本轮交付范围

阶段1：项目骨架 + 主屏打字闭环。

- 默认机 1920s 直立式座机、默认纸信纸、默认色带黑、默认英文字体 Courier Prime、音效包 v1。
- 自绘英文 QWERTY 键盘（容器级 onTouch、弹簧曲线、按下约 0.92 缩放、只动 transform/透明度）。
- 纸面 List + LazyForEach + @Reusable（纸纹只作背景，格线/边距/红格/页眉代码层画）。
- SoundPool 预加载整机音包、TouchType.Down 当刻播音、震动 15–30ms、行末约 8 字预告铃。
- 首屏标准：打开即美机 + 纸 + 引导。
- 两类引导：首次使用引导（只看一次）+ 常驻引导（每张新纸一行、输入后消失），文案走资源占位句。

## 6. 出入项（与文档/任务书不一致之处，均实测）

1. **`rate` 参数不可用于浮点微随机**：调研报告建议"rate 0.97–1.03"，但 SDK 真 d.ts 中 `PlayParameters.rate` 是 `AudioRendererRate` 离散枚举（0/1/2）。实际改用同文件 `PlayParameters.pitch`（0.25–4.0，@since 26.0.0），并对 401 做"关掉 pitch 重放一次"的降级。
2. **SDK 路径**：d.ts 真实位置是 `sdk/default/openharmony/ets/api/`，不是 `sdk/26.0.0/ets/api/`（后者无 api 目录）。
3. **信纸不画横线**：`PaperSpec.hasGrid` 仅稿纸为 true，信纸目前只有页眉双细线与文字行；风格板未明确信纸是否需要横格线，待用户定。
4. **光标只画行首一条墨条**：阶段1 的 `PaperRow` 不含行内 offset，行内光标跟随留到阶段3 接 `CursorPos.offset`。
5. **手指滑过换键只发声不上屏**：键盘实现为"滑入只按下视觉 + 音效，不落字"，避免误落字；如需滑入也上屏需改一行。
6. **`SHIFT` / `SWITCH_LANGUAGE` 也走 `onCommit(ch='')`**：按契约"ch 为空串 = 纯功能键"，主屏把它们当 no-op。
7. **上游记录瑕疵**：`assets/sounds/freesound/SOURCE.txt` 中 `key-01-ddohler-9098.wav` 的 SHA-256 记录为 63 位且与实测不符；rawfile 的 SOURCE.txt 已用实测值并注明，未改上游原文件。
8. **弃用 API 替换（2026-11-03 收尾）**：
   - `font.registerFont()`（全局，API 26 弃用）→ `UIContext.getFont().registerFont()`（`@ohos.arkui.UIContext.d.ts:4440` getFont → `Font:69` registerFont，参数仍是 `font.FontOptions`）。落点 `pages/Index.ets` registerPaperFonts()。
   - `getContext()`（全局，API 18 起弃用）→ 删除兜底，改为**必须显式注入** `AudioService.attachContext()`；页面在 preload() 前注入，未注入则静默降级并记日志。落点 `services/AudioService.ets` resolveResourceManager()。
   - `DocStore` 文件 I/O 全部就地 try/catch（`writeText` / `readText` / 新增 `closeQuietly`），消除 7 条 "Function may throw exceptions" 提示。
   - 复测：构建 `BUILD SUCCESSFUL`、单测 21/21 通过、`has been deprecated` 计数归零（119 → 105 条 WARN，剩余全在 ngf_framework 与 SDK 能力提示）。

## 7. 无法独立验证项（必须真机，沙箱内不能声称已验证）

**本期没有任何真机验证**：`hdc list targets` 返回 `[Empty]`（仅 COM 串口），USB 设备树只有 HUAWEI FreeClip 蓝牙耳机，本地模拟器 `lists.json` 为空。用户已确认"真机稍后给，先只做可构建可验证部分"。

因此以下全部**未验证**：

1. 首屏 3 秒内敲出第一声（真机帧率、SoundPool 首音延迟）。
2. SoundPool 同 soundId 重叠到底是"停旧启新"还是"多流重叠"（定义稿 §8.1 第 4 项）。
3. 震动在系统触感关闭时的表现；`pitch` 是否被设备运行时接受。
4. 自定义字体 `font.registerFont` 真机注册结果；rawfile 打包后 `keyboard/keycaps.json` 可达性。
5. 多点触控手感、弹簧曲线观感、按键音与震动同步顺序。
6. Canvas 固定层竖线 + 行内横线的视觉对齐；@Reusable 复用后行数据刷新。
7. HAP 真机安装（当前产物未签名；`build-profile.json5` 的本地签名配置含口令，**不得入库**）。
