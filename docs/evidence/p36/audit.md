### A2. 横尺三角呈黑色、非设计红；左三角与中央指针挤在同一 x 位
- 设计：左右边距三角＋中央指针尖同为红 `#c8322d`（增补 §5.3、26 号稿 §6.2）。
- 证据：

    即横尺上没有任何红色像素，三角不是红。
  - 1761 中央裁切（x 580–660px、y 1190–1290px）：两枚黑色下指三角上下叠放，
    不是红色；左部裁切（x 80–160px）无三角。
  - 代码 `Carriage26.ets`：两枚三角均 `.fill('#c8322d')`（L217、L220），
    但渲染为黑——填充未生效，或被别的 Path／层盖住。
- 另：左三角的 x 计算式 `(PAPER_LEFT + 25 - (CX0 - 350))` 与中央指针 x 重合，
  截图里两枚三角挤在同一 x 位。需核对三角 x 与指针 x 是否重合；若重合，
  应把左三角改到纸左缘（156vp）或在设计里写明接受同位。
- 算过：三枚三角（左／右／中央指针尖）均为红 `#c8322d`、位置分明；
  V=0／行中／行末各一张横尺特写，像素量测红三角存在。

### A3. 纸面残留拼音字母 "nij"（输入法缓冲 bug）
- 证据：1774 纸面第二行 `aaaaaaanij好,`；自检 dump `aaaaaanij好,`；
  自检不符点 5："第三次输入时内置会话残留 `jao` 缓冲，补按 `m/a` 落成逗号"。
- 机理：拼音会话残留字母未转换／未清空就落字，原始拼音直接上了纸面。
  正常行为：拼音字母要么选词上屏、要么退格清掉，不应以原文留在纸上。
- 算过：连续输 3 个中文词（如 你／好／吗），纸面无残留拼音字母；
  中途退格／换词后缓冲清空，dump 核对。

### A5. 滑出动画 300ms 未逐帧验真（1774 取证方法有问题）
- 证据：自检不符点 3——单帧截图 400–500ms ＞ 300ms 动画窗口，
  临时把时长调到 1200ms 抓帧得 1774，随后恢复 300ms 重装；终版 300ms 未被逐帧验。
