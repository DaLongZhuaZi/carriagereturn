## 结论先行

**质感奇怪的根因只有一个：我们的"盖"是一张木纹照片，原版的"盖"是一块光滑的珐琅／金属。**
原版三张图＋视频里没有任何木纹——机身是通体光滑、均匀、哑光的薄荷绿珐琅，
表面零纹理、零粗糙、零明暗斑驳。我们的 1920s 机是深棕木纹贴片（`tile-1920s-base-v2.png`），
纹理线、结节、明暗起伏全是照片感，贴在屏幕上像一张"木头照片"，不是一块"材料"。
颜色（深棕 vs 薄荷绿）是选品问题，质感（照片 vs 材料）才是现在的问题：
即使保持深棕，盖也应该是光滑的深棕珐琅，而不是木纹。

## 逐项对比

### 1. 机身／盖（最大差距，根因）
| | 原版 Foldtype | 当前实现（1920s） |
|---|---|---|
| 材质 | 光滑珐琅／喷塑金属，哑光、均匀 | 木纹照片贴片，有纹理线、结节、明暗斑驳 |
| 表面 | 零纹理，通体同一色、无明暗斑驳 | 木纹走向明显，左右有深浅带，视觉上"忙" |
| 光泽 | 柔和均匀的漫反射，无高光点 | 贴片本身无光泽感，靠 4 停渐变＋亮带"画"光泽，像贴纸 |
| 观感 | 一块做出来的产品，有厚度、有实体感 | 一张贴上去的图片，平、假、像壁纸 |

- 证据：1780／1788 的盖面，木纹线在纸下方、字篮两侧、键盘上方全屏可见，
  纹理走向与零件无关，是一层"背景图"；原版图 2 的薄荷绿盖面通体均匀，
  只有零件的阴影，没有任何底纹。
- 连带：木纹太"忙"，把字篮扇（深色）和纸（米色）的对比都压弱了；
  原版薄荷绿底色浅，银扇、白键、黑字都跳得出来。

### 2. 键帽
| | 原版 | 当前实现 |
|---|---|---|
| 材质 | 哑光白／米白塑料，扁平、边缘柔和、阴影软 | 3D 生成帽身，高光强、棱角锐、偏"塑料玩具"光泽 |
| 图例 | 小、深色、居中，字很细 | 图例偏大、偏粗，帽身高光抢眼 |
| 键缝 | 缝里能看到键杆／下层机构，深色均匀 | 缝里是黑色井底，帽间高光连成一片，显"亮" |

- 差距没有盖那么大，但帽身的高光和棱角让键盘区看起来比原版"硬"、"亮"。
  原版键帽是"扁平哑光"，我们的是"立体高光"。

### 3. 字篮扇
| | 原版 | 当前实现 |
|---|---|---|
| 材质 | 细而轻的银色金属字杆，扇形舒展、透光感 | 生成图 `basket-fan-3d.png`，偏深、偏重、对比强 |
| 背景 | 浅薄荷绿底，银扇清晰 | 深棕木纹底，深扇发暗，扇与底糊在一起 |
| 字模 | 扇上字模清晰可辨（金属字钉） | 字模在显示尺寸下不可辨（已接受现状，见增补稿） |

- 扇本身的问题一半在扇图（偏深偏重），一半在底（木纹太暗，扇显不出来）。
  换成浅色光滑底，扇会立刻清楚一档。

### 4. 纸
| | 原版 | 当前实现 |
|---|---|---|
| 颜色 | 白色（#fff 上下） | 米色／淡黄 `#eee4ce` |
| 质感 | 平整白纸，黑字 | 偏黄，卷曲处有阴影 |

- 纸偏黄是小问题，但原版是白纸。纸白一度，整机立刻亮一档。

### 5. 金属件（滚筒／旋钮／横尺／压杆）
- 原版：滚筒、旋钮、横尺都是干净的银色金属，抛光均匀、反光柔和。
- 当前：滚筒深钢渐变、旋钮金属图、横尺银灰——这几件做得还可以，接近原版。
  横尺三角已改红（1783 量测确认），金属件不是主要问题。

### 6. 整体光感
- 原版：明亮、均匀、通透，像在亮 studio 里拍的产品照；光是"环境光"，没有方向性硬阴影。
- 当前：偏暗、偏闷，木纹＋深扇＋黑井把亮度压下去；4 停柔光渐变是"画"出来的明暗，
  不是材料本身的光感，所以看起来假。
  （这与 B4 盖子均值偏差 3.8 同根：渐变"画"光泽的同时把均值推离 token。）

## 方向建议（等用户定夺，不擅自写提示词）

**A. 换材质、不换色（最小改动）**：四机颜色 token 不动，把"木纹贴片"换成"光滑珐琅"——
盖面改为通体均匀的纯色＋极轻的纵向明暗（只做清漆光泽，不做纹理），
木纹贴片停用。深棕 1920s 就变成"深棕珐琅"，其余三机同理。工作量最小，质感立刻接近原版。

**B. 换材质＋换色（向原版对齐）**：盖面改薄荷绿系光滑珐琅（按原版图 2 的薄荷绿取色），
四机 token 重定（或只把 1950s／1960s 改成薄荷绿系，1920s／1930s 保留深色珐琅）。
改动大，但最接近原版参考。

**C. 只调光、不换材质**：保留木纹贴片，只把柔光渐变调弱／调匀（B4 微调）。
不推荐——木纹照片本身是根因，调光盖不住"照片感"，治标不治本。

无论 A 或 B，都应同步做：纸改白一度（`#f7f2e8`→近白）、键帽高光减弱（哑光化）、
扇图提亮（或换浅底后复评）。这三项是"质感"的一部分，不是单独任务。
