## 1. 拍摄前置（血泪教训，顺序不许省）

0. **先消除引导（可操作口径）**：安装后首次启动会弹启动引导与打字机页引导；逐条点「跳过／知道了」走完，重启一次确认不再弹（`ONBOARDING_SEEN` 与 `guide.*.seen` 已写）。发布构建无回归模式，不要依赖测试钩子；也不要在引导浮层未消时拍门图（浮层会盖住 0.40–0.98 区域，差异会被误判回归）。
1. 确认 App 在前台：需要冷启动时 `aa force-stop com.dlzz.carriagereturn` → `aa start -a EntryAbility -b com.dlzz.carriagereturn` → sleep 6–8s → dump 看到 App 自己的文本（「未命名」「卷宗」「Courier Prime」）才继续。本机 `input` 命令不存在（`/bin/sh: input: inaccessible or not found`，2026-11-25 批 81 实测），不要依赖 `input keyevent 3`。
2. 任何交互后**等 ≥1 秒**。
3. **确认拨杆已回静止位**（截图目视或与基线对比右区）；不许用"测试主动复位"代替等待——复位后拍的门图验证的是复位后的静止态，会盖住状态泄漏的 bug（复位仅用于隔离验证的对照组）。
4. 同一设备（MLR-AL10 平板 1600×2560；Nova ADA-AL00U 手机 1224×2776）、同一亮度/主题、同一页面状态（空纸）。
5. **当前版式空纸 parts（2026-11-25 批 81 实测）**：平板 `paperTop=295.6 paperBox=109.6`、手机 `paperTop=124.9 paperBox=87.0`（vp）。批 13 旧版式的 281.8／123.4、206.0／96.0 已不适用；非该值说明纸容器因文档内容而变高，不得入镜。
