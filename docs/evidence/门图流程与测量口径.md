# 门图流程与测量口径（第 0 批固化）

* **定稿:** 2026-11-09
* **事实源:** 总纲 Verification Plan＋AGENTS.md 追加条（本批写入）
* **工具:** `tools/gate-compare.py`
* **基线:** `docs/shots/332_metal3.jpeg`（1920s 冻结基准）

## 1. 拍摄前置（血泪教训，顺序不许省）

0. **先消除引导（可操作口径）**：安装后首次启动会弹启动引导与打字机页引导；逐条点「跳过／知道了」走完，重启一次确认不再弹（`ONBOARDING_SEEN` 与 `guide.*.seen` 已写）。发布构建无回归模式，不要依赖测试钩子；也不要在引导浮层未消时拍门图（浮层会盖住 0.40–0.98 区域，差异会被误判回归）。
1. 确认 App 在前台：`input keyevent 3` → `aa start -a EntryAbility -b com.dlzz.carriagereturn` → sleep 6–8s → dump 看到 App 自己的文本（「未命名」「卷宗」「Courier Prime」）才继续。
2. 任何交互后**等 ≥1 秒**。
3. **确认拨杆已回静止位**（截图目视或与基线对比右区）；不许用"测试主动复位"代替等待——复位后拍的门图验证的是复位后的静止态，会盖住状态泄漏的 bug（复位仅用于隔离验证的对照组）。
4. 同一设备（MLR-AL10 平板 1600×2560）、同一亮度/主题、同一页面状态（空纸）。

## 2. 测量口径（写死）

| 区域 | x 范围 | y 范围 |
|---|---|---|
| 键盘区 | 0.00–1.00 | 0.62–0.98 |
| 车架左区 | 0.00–0.33 | 0.40–0.62 |
| 车架中区 | 0.33–0.67 | 0.40–0.62 |
| 车架右区 | 0.67–1.00 | 0.40–0.62 |

* 阈值 **30**：像素的 `max(|dR|,|dG|,|dB|) > 30` 计为"不同"。
* 纸面整体排除；状态栏（顶部 5%）在区域之外，天然排除。
* **通过判据：四区"超阈值像素占比"全部为 0.00%**（即每区 0 个超阈像素）。
* 历史对比口径可加 `--scale 400x640`（降采样后比对）。

## 3. 工具用法与自测

```bash
python tools/gate-compare.py docs/shots/332_metal3.jpeg <当前截图> --scale 400x640
python tools/gate-compare.py --self-test
```

`--self-test` 覆盖 9 项：同图 0.00%、+20 差忽略（≤30）、+60 差命中、区域隔离、纸面排除、状态栏排除、键盘命中、四区非空、车架三区拼满整宽。**本机自测 PASS（0 失败）**。

## 4. 本批实测复核（2026-11-09，沙箱）

| 对比 | 键盘 | 车架左 | 车架中 | 车架右 | 结论 |
|---|---|---|---|---|---|
| `500_gate.jpeg` vs `332_metal3.jpeg`（400×640） | 0.00% | 0.00% | 0.00% | 0.00% | **PASS**（四区全 0） |
| `540_1920s_gate.jpeg` vs `332_metal3.jpeg`（400×640） | 0.00% | 0.00% | 0.00% | **1.99%（370 px，maxdiff 119）** | **FAIL** |

**结论**：
* 500 vs 332 复现了四区 0.00%，说明工具口径可用。
* 540 vs 332 **不能复现**总纲/旧自检记录里的"0.00%"：右区 1.99% 与总纲所述"沙箱未复现（键盘 0.03%、车架左 0.41%、车架右 1.89%）"方向一致（差异来自降采样算法），根因是**拨杆静止角不同**（540 拍摄时拨杆未回静止位），其余零件一致。
* 因此：**540 不得作为本批门图通过证据**；第 0／1 批门图必须按 §1 前置重拍。本批无设备，B6 记"设备离线、未验"，替代证据为工具自测＋几何常量冻结测试＋改动面审查（不改 1920s 图片/几何/静止角）。
