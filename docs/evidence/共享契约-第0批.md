* **定稿:** 2026-11-09（第 0 批）

## 1. prefs 键命名空间与登记表

| 命名空间 | 形式 | 归属 | 说明 |
|---|---|---|---|
| `guide.*` | `guide.<page>.seen` | F1／F2 | 每页首次引导；首次启动复用既有 `onboarding_seen` |
| `custom.font.*` | `custom.font.<machine>.<field>` | F3 | 每机字体搭配（family／size） |
| `custom.paper.*` | `custom.paper.<field>` | F3 | 纸张颜色／横线／边距／纹理 |
| `stats.*` | `stats.day.key`、`stats.day.chars`、`stats.daily_goal`、`stats.event.<name>` | F11／F5 | 日计数器与事件计数（标量） |
| `achieve.*` | `achieve.<id>` | F5 | 成就解锁状态 |

代码位置：`services/AppPreferences.ets` 的 `PrefKeys`（键与 builder）＋`PrefRegistry`（登记表＋`isRegistered()`）。
**规则**：任何新键必须 ① 在 `PrefKeys` 加常量/builder；② 在 `PrefRegistry.specs()` 登记；③ 不得在组件里裸写字符串键。`check-contracts.py` 会核对命名空间与 builder 存在。

## 2. StatsService（单一派生层）

```text
StatsService
  totalWords(): number          // docStore.listActive() 的 charCount 求和（唯一实现）
  consecutiveDays(): number     // active 文档 updatedAt 去重自然日，以今天为终点
  todayChars(): number          // prefs 日计数器；跨日读为 0
  recordChars(n: number): void  // 保存事件时批量记，不走打字热路径
  dailyGoal(): number           // 默认 500
  setDailyGoal(n: number): void
  goalProgress(): number        // 0..1
  recordEvent(e: string): void  // 事件名见下
  eventCount(e: string): number
```

* **事件名枚举（字符串常量类 `StatsEvents`）**：`doc_saved`、`doc_exported`、`font_changed`、`ribbon_changed`、`paper_changed`、`fold_typed`。
* **不建追加式事件账本**（总纲已砍 StatsLedger）；统计走 DocStore 派生＋prefs 计数器。
* **"天"的定义**：自然日（Asia/Hong_Kong，`tzOffsetMinutes=480`）；有任意落字（≥1 字）即计一天；今天无落字＝连续 0 天（与 HomePage 既有口径一致）。
* **纯函数**：`model/StatsCore.ets`（`dayKey`／`dayIndex`／`consecutiveDays`／`sumCounts`／`progressRatio`／`goalReached`），可 Node 单测。
* **接线批**：第 4 批 HomePage 统计行迁到本服务；第 6 批 F5 消费。

## 3. DocStore 状态模型（第 0 批只定模型，第 6 批翻转语义）

```text
DocIndexRecord { id, title, createdAt, updatedAt, dossierId?, machine?, paper?,
                 state?: 'active' | 'trashed', trashedAt?: number, origDossierId?: string|null }
DocStore
  trash(id, nowMs): boolean      // active → trashed；记时间与原卷宗；从卷宗移出
  restore(id): boolean           // trashed → active；回原卷宗
  rename(id, title): boolean     // trim；空标题不改
  search(query, opts): DocSearchHit[]  // 标题＋正文；默认只搜 active；limit 默认 20
  listTrashed(): DocSummary[]
  listActive(): DocSummary[]     // 第 0 批起 StatsService 用
  activeCount(): number
```

* **本批不改**：`remove()` 仍硬删；`list()` 仍返回全部 entries（含 trashed 的过滤第 6 批才切）。
* **旧文档缺字段默认值**：`state` 缺省＝`active`（`stateOf()` 已实现并有单测）。
* **纯逻辑**：`model/DocStoreStateCore.ets`（trashRecord／restoreRecord／renameRecord／searchRecords／activeRecords／trashedRecords），I/O 留在 `DocStore.ets`。

## 4. FileHelper／ShareService／FontService 边界

| 服务 | 职责 | 不做什么 |
|---|---|---|
| `FileHelper` | DocumentViewPicker 选文件（字体 .ttf/.otf）、PhotoViewPicker 选图、DocumentSaveOptions 保存到用户位置、uri→沙箱拷贝、`statOf` | 不做文件头校验（FontService/第 2 批）、不做图片尺寸校验（第 3 批）、不写业务 UI |
| `ShareService` | 分享唯一入口 `shareFile(ctx, path, utd): Promise<ShareResult{shown,error}>`；`shown` 只证"面板调起" | 不宣称"已分享成功"；不做碰一碰传输（第 3 批按探针） |
| `FontService` | `registerBundled(ui, fonts)` 复用启动注册循环（唯一实现）；`registerFromFile(ui, familyName, filePath)` 第 2 批用 | 不另写第二套注册逻辑；不做字体列表管理 UI |

**Index 接线现状**：字体注册调 `FontService.registerBundled`；`shareFile()` wrapper 调 `ShareService.shareFile`（3 个导出入口仍经 wrapper）；`systemShare` 只允许出现在 `ShareService.ets`。

## 5. 提示机制分工（不许合并）

| 机制 | 生命周期 | 用途 | 组件 |
|---|---|---|---|
| HintBar | 顶部下滑、3 秒自消失、点按关闭 | 瞬时操作反馈／锁定提示 | 既有 `HintBar.ets` |
| GuideOverlay | 常驻直到关闭；首次进页 | 首次引导浮层（2–4 条） | 新增 `GuideOverlay.ets` |
| 常驻说明行 | 常驻 | 静态说明（如设置页底部隐私声明） | 各页自渲染 |
| AppDialog | 模态 | 成就达成提示／确认弹窗 | 既有 `AppDialog.ets` |

**GuideOverlay 契约**：`GuideAnchor{id?, role?}` 语义锚（不写死坐标）；`GuideStep{text, anchor?}`；props `visible/title/steps/anchor/showSkip/onNext/onSkip/onClose`。遮罩与卡片是 Stack 兄弟节点（点遮罩关、点卡片不关）。
