# 新页导航注册契约与沉浸式检查清单（第 0 批）

* **定稿:** 2026-11-09
* **事实源:** AGENTS.md「页面与沉浸式」「导航」；`docs/界面重设计稿.md` §2.10
* **适用:** 第 2 批 FontManagerPage／PaperCustomPage、第 6 批回收站页与词库管理页等一切新覆盖层

## 1. 导航注册契约（全 App 只有一个 @Entry：Index.ets）

新页不是路由页面，是 Index 的覆盖层。注册步骤（缺一步就算没接好）：

1. **状态**：在 Index 增加 `@State xxxOpen: boolean = false`（或复用 navStack 的 key）。
2. **push/pop**：`pushPage('xxx')`／`popPage()`／`popTo('home')` 走 Index 既有方法；禁止 `@ohos.router`、`terminateSelf`、`finish`。
3. **渲染顺序**：覆盖层按层级排在 `Index.build()` 的 Stack 中，后渲染者盖先渲染者；主页常驻但栈顶不是 home 时让位；详情页必须排在它所属列表页之后。
4. **过渡**：新页根节点 `.transition(TransitionEffect.move(TransitionEdge.END).animation({ duration: 250, curve: Curve.EaseOut }))`；冷启动首帧不播动画。
5. **系统返回**：`Index.onBackPress()` 统一弹栈；页内返回按钮调同一个 `popPage()`，不许各写各的。
6. **中文输入**：从打字机离页前先 `applyChineseMode(false)`＋`langZh=false`（既有离页逻辑）；新页不得让系统键盘悬空。
7. **页面壳**：新页内部用 `PageShell`（如适用）并让出入参 `widthVp/heightVp`。

## 2. 沉浸式检查清单（§2.10，逐项打勾）

- [ ] 页面 `aboutToAppear` 调用 `applyImmersive(this.getUIContext())`，取得 `topInset/bottomInset`。
- [ ] 根节点 `Stack` 加 `.expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])`。
- [ ] 顶栏/页眉顶距 = `topInset`（不许写死固定值）。
- [ ] 底部内容底距 = `bottomInset`（列表末尾留白用 `Column().height(bottomInset)`）。
- [ ] `aboutToDisappear` 不恢复非沉浸。
- [ ] 页面切换 250ms 右进左出；不闪（新页首帧不透明，旧页过渡结束前不卸载）。
- [ ] 返回按钮与系统返回同一套弹栈。
- [ ] 与主页层叠顺序正确（dump 节点存在 ≠ 可见，验收以截图为准）。

## 3. 检查方式（每批）

1. `grep -n "applyImmersive" entry/src/main/ets/components/<NewPage>.ets` 必须有命中。
2. `grep -n "expandSafeArea"` 必须有命中。
3. `grep -n "router\\."` 必须无命中（新页）。
4. 真机截图（操作前/后）核对顶/底不被状态栏/手势条压住；本机无设备时记"未验"并列入第 7 批冒烟。
5. 导航：进入→系统返回→回到来源页（不是一律回主页），截图前后各一张。
