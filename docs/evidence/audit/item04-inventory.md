## 3. 已确认没问题的点

- **主色体系**：`#e8ddc9`（69 处）＋ `#c9a45c`（56 处）＋ 近黑底，跨 14 页一致；五台机切换不改这套 UI 色（机器色只进拟物件），观感不跳。
- **正文/次要文字层级**：`rgba(232,221,201,0.6/0.5/0.4)` 三档承担「值 / 提示 / 分区标题」，语义稳定。
- **行高与分割线**：SettingsRow 固定 52vp、1vp 分割线 `rgba(232,221,201,0.12)`，设置/拼音/主题三页一致。
- **危险操作色**：删除类一律红色、恢复类金色，回收站与内页一致。
- **双机布局**：同一组件在两端的相对位置与层级一致，差异只在绝对宽度（响应式正常）。
- **五台机协调**：收藏页五卡视觉协调（同裁切比例、同圆角、同徽标位置），旧机做旧与新机干净之间有明确风格区分，不算冲突。
