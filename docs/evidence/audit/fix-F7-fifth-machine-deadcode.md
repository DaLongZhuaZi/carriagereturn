## 7. 返工：修收藏页五卡裁切（2026-11-26）

**原因**：`CollectionPage.body()` 里 Grid 用 `layoutWeight(1)`，和固定 250vp 的成就列表抢剩余高度；手机上 Grid 只分到两行高，第三行卡片被裁掉、2020s 完全不可见。

**改法**：
- 整页改成一个 `Scroll`，成就列表不再用固定高内层滚动，而是自然排在网格下面；
- Grid 高度按列数计算（`gridHeight()`：`ceil(5/列数) × 380vp + 行距`），5 张卡各得完整高度；
- 新增 `colCount()` 从 `columnsTemplate` 数 `1fr`。

改动：`CollectionPage.ets` +57/−44。构建通过（signed hap）。
