# 文案资源约定（第 0 批）

* **定稿:** 2026-11-09
* **事实源:** AGENTS.md「语言与编码」；总纲「文案约定」
* **原则:** 全部面向用户的文案走资源文件（`entry/src/main/resources/base/element/string.json`），不硬编码在渲染逻辑里。

## 1. 键命名

| 类别 | 形式 | 例 |
|---|---|---|
| 引导 | `guide_<page>_<n>` | `guide_home_1`＝"这是一台打字机……" |
| 自定义 | `custom_<area>_<n>` | `custom_font_import_failed` |
| 统计 | `stats_<n>` | `stats_daily_goal` |
| 分享/导出 | `share_<n>` | `share_saved_and_opened`（"已保存＋已调起分享"） |
| 通用 | `common_<n>` | `common_ok`／`common_cancel` |

* `<page>` 用稳定英文 id（home／dossier／dossier_detail／document_view／collection／collection_detail／customize／settings／export／pinyin_settings／typewriter／font_manager／paper_custom／trash），不用中文标题。
* 一个语义一个键；同文案在不同语境要拆键（便于改一处不影响另一处）。

## 2. 放置与读取

* 文件：`entry/src/main/resources/base/element/string.json`（既有文件追加）。
* 读取：`$r('app.string.<key>')`；Index 已有 `resolveString()` 可用于需要字符串的场景。
* 资源缺失时 `$r` 会在编译期报错（这是好事，逼登记）；不许用 `??` 静默兜底。

## 3. 迁移与门控

* **第 0 批不迁移存量文案**（大改易回归）；存量保持现状。
* **第 1 批起新文案必须走资源文件**；第 1 批的引导文案全部按本约定落 `string.json`。
* 禁止：在 `build()`/`@Builder` 里写中文字面量；emoji；把文案拼进日志（日志用英文诊断串）。

## 4. 检查

`node tools/check-arkts.mjs` 不检查文案（避免误报存量）；每批人工抽查新增文件：
`grep -nP "[\x{4e00}-\x{9fff}]" <NewFile>.ets` 的命中应只出现在注释与 `$r` 键名之外（新增文件）；评审时列为必查项。
