# 原版视频解析：Hanx Writer 各页面设计要点

> 解析对象：Instagram @livetypewriterpoet 2025-10-11 实拍 reel（95 秒，竖屏手机录屏）+ TechCrunch 2014-08-18 真机演示（123 秒，横屏 iPad）+ App Store 官方截图 10 张（iPad 5 + iPhone 5，挂图对应 1.2.2 / 2017 版）。
> 2026-11-03 用户定：**以 2025 版 reel 为准，2014 版演示已过时、仅作历史注记，不作设计依据；两版冲突时以新版为准**。
> 阅读前提：
> - reel 画面里的葡萄牙语 / 花字字幕是创作者后期加的，不是 App UI，解析时已全部排除。
> - 2014 版与 2025 版有版本差（见末尾），文档写的是两版共有的结构，版本差单独标出。
> - 本文档只解析“页面长什么样、动效怎么走”，供回车对标动法与结构；**不抄外观、不拿原版图当素材**，回车机器仍以本仓虚构机为准。
> - reel 只有 480×854，细部字号与间距无法精确量取，本文只写结构级要点，不编像素数。

## 1. 欢迎 / 新功能页（reel 开头）

- 顶栏：左侧 “Welcome Back!”，右侧 “Done” 文字按钮。
- 上半部是一封打字机字体写成的信（只露局部），下面是大标题 “Welcome.” + 一行 “Hanx Writer has some new features!”。
- 中部是 5 张横向新机横幅卡（Del Sol / Electrix / Matterhorn / Golden Touch / Prime Select），每张是机器照片 + 机型名。
- 下方文案 “Complete Tom's signature collection” + 手写体签名 “Tom Hanks himself”，底部 4 个页点（轮播指示）。
- 设计要点：**新功能页 = 信 + 大标题 + 横幅卡 + 收藏 upsell + 签名**，不是功能列表；签名是品牌资产位，不是装饰。

## 2. 打字主界面（两段视频 + 截图共有的核心页）

- 顶栏（深底）：左侧文件夹图标（文档库入口），中间文档标题（默认 “Untitled”），右侧汉堡菜单。
- 纸面区：深炭色底上放一张白纸；纸的下沿压着银色压纸卷 + 纸挡（reel 里只露局部，TC 特写里看得清）；纸面文字是打字机字体、左对齐。
- 右侧页码轨（竖屏手机版）：一列小控件，自上而下是上箭头、当前页码、+ 号（加页）；多页时下箭头出现。页码轨贴在纸面右缘，不占顶栏。
- 键盘区：自绘键盘，占下半屏；分两档——字母档（QWERTY + Shift + 123 切换 + 删除 + return）与符号档（数字行 + / : ; ( ) $ & @ 等 + #+= / ABC 切换 + 删除 + return）。删除键是方框内带 X 的图标，return 键是浅色宽键。
- 配色跟机型走：**以 2025 版为准，深色键 + 浅字**；707 是薄荷绿键。2014 版 Prime Select 的浅色键已过时，不作依据。**键盘不是一套固定配色，是机型主题的一部分**。
- 横屏 iPad 版与 “Preview Mode” 角标只见于 2014 版，已过时；竖屏手机版（2025 版）纸面居中偏右，以新版为准。
- 动效（视频里实际可见）：按键按下有下沉（幅度不大、回弹快）；纸面随打字推进；行末有铃声（reel 旁白提到，画面无铃铛特写）。

## 3. 侧边菜单（从右侧滑入，盖住纸面一部分）

- 底色深炭，顶部是汉堡图标 + 打字机字体 “Hanx Writer”。
- 导航项（每项左侧一个线形小图标）：View Typewriters、Create New Document、My Documents、Share Document、Typewriter Settings、Keyboard Extension。
- 格式化控件区（导航项下方）：四颗薄荷绿实心按钮——Font Sizes、Font Styles、Text Alignment、Ribbon Colors；老版截图里对应位置是底部三段对齐分段钮 + 色带 A 标（红 / 蓝）。
- 设计要点：**菜单 = 导航 + 格式化，两区上下排布，不分页**；滑入动画是从右向左盖住纸面，纸面左侧仍露出一部分。

## 4. 收藏商店 Collection（横向卡片轮播 + 底部金条）

- 顶栏：左侧 “Back”，中间 “Collection”，右侧 “Restore”（恢复购买）。
- 卡片轮播：横向滑动，左右邻卡露边；单张卡片结构自上而下是——
  1. 机型徽标（707 是翼形徽章，Del Sol 是 HANX 字母徽 + 手写体名，Matterhorn 是白底红标，Prime Select 是手写体名）；
  2. 打字机字体标语（707：“Bold enough for any journey, on and off the page.”；Prime Select：“A writer's best friend and confidant. SHOOK. SHOOK.”；Del Sol：“Fearless creativity glows bright & brilliant.”；Matterhorn：“An awe-inspiring Swiss classic - sharp & imposing.”；Golden Touch：“Sleek and elegant, inspiration at your fingertips.”；Electrix：“Write your story, your way. Never compromise.”）；
  3. 机器照片（卡片主视觉）；
  4. 两个按钮：描边钮 “Try Me!”（试用）+ 浅色实心钮 “Add to Collection”（购买）；
  5. 功能清单（每机 3 条，各不相同：707 是 Background UI Colors / Red & Blue Ribbons / Multiple Documents；Matterhorn 是 Large Typeface Option / Multiple Documents；Golden Touch 是 Text Alignment / Title Page & Picture / Multiple Documents；Del Sol 是 Custom Stationery / Multiple Documents；Electrix 是 Use any Typeface in Collection / Multiple Documents）；
  6. 机型专属小图标（707 左下是色带卷，Matterhorn 右下是 AA 大字号标）。
- 卡片底色 = 机型色（707 薄荷绿、Del Sol 金橙、Matterhorn 红、Golden Touch 米白、Electrix 蓝灰、Prime Select 深灰）。
- 底部常驻金条：左侧 “Signature Collection”，右侧 “Get It Now” 按钮。
- Bundle 弹层（点金条弹出）：右上角 “Close”，手写签名 + “Signature Collection” 标题 + 文案 “Save on the Signature Collection! Collect all currently available typewriters and enjoy more Hanx Writer features.”，下面 5 条机型横幅，底部金钮 “Complete Your Collection for only $9.99”。

## 5. 机型选择弹窗（打字页上浮白卡，老版截图）

- 不进商店也能换机：打字页上方浮出一张白卡，逐行列出机型——缩略图 + 机型名 + 标语，右侧薄荷绿按钮，已拥有显示 “Select”，未拥有显示 “Add”（带小图标）。
- 设计要点：**换机有两个入口——商店轮播（带营销）与打字页弹窗（纯切换）**，弹窗无标语以外的营销内容。

## 6. 键盘扩展 Keyboard Extension（商店内一张 mint 卡 + 详情页）

- 商店卡：薄荷绿底，标题 “Keyboard Extension”，文案 “Enjoy the unique typing sounds and looks of Hanx Writer when you write text messages, emails, notes, and more. Works with most third party apps that use a keyboard.”，配一张手机 mockup（小 Hanx 键盘在另一个 App 里），只有一个 “Add to Collection” 钮（无 Try Me）。
- 详情页：深底，手机 mockup 放大（Messages 界面 + Hanx 小键盘：浅色小键 + 123 / 地球 / return），标题 “Hanx Keyboard”，文案 “Use your favorite Hanx Writer … default keyboard in all of your …”，底部绿钮 “Add Hanx Keyboard”。
- 设计要点：扩展的卖点文案只讲两件事——**声音与外观跟随到别的 App**，不讲输入法功能。

## 7. 文档库与文档视图（截图，2017 版挂图；新版 reel 未覆盖，作结构参考）

- 文档库：顶栏 “Documents” + 右侧 “Close”；卡片显示标题 + “1 Page, 234 Words” + 分享 / 删除图标。
- 文档视图：顶栏是返回 “Documents” + 文档标题（如 “greetings!”）+ “Close”；主区深炭底，左侧是标题页（白纸 + 右上角斜贴的照片 + 下方小题注），下方标注 “Title Page”，右侧是正文页（打字机字体）；底栏三个钮：+（加页）、分享（方框上箭头）、删除（垃圾桶）。
- 设计要点：**标题页与正文页是并排的两张纸**，不是同一页的上下段；标题页的照片是斜贴的，有意做旧感。

## 8. 分享（系统面板，不是自绘 UI）

- 2014 版演示里点分享后拉起的是 iOS 系统分享面板：上排 Message、Mail，下排 Copy、Print。新版 reel 未拍到分享流程，此条列为历史证据、待新版验证。
- 设计要点：**导出不做自绘分享页，直接走系统分享**；回车已定的 fileUri 分享路线与此一致。

## 9. 动效总表（视频里实际看见 vs 没看见）

实际看见（以 2025 版 reel 为准）：
- 按键下沉 + 快速回弹（reel 打字段可见，幅度小、节奏快）。
- 菜单从右侧滑入盖住纸面；商店卡片横向滑动、邻卡露边；Bundle 弹层自下而上出现。
- 纸面随打字推进；页码轨数字随翻页变化；换机后键盘配色整体切换。
- 行末铃声（reel 旁白提到，无铃铛视觉特写）。

仅旧版见过（历史注记，不作依据）：
- 分享面板系统弹出、横屏 iPad 打字、Preview Mode 角标、浅色键盘——均只见于 2014 版。

没看见（不要按想象写进实现）：
- **字杆摆动全程未入镜**：reel 只拍到压纸卷局部，TC 只拍到纸与键，杆的摆动幅度与轨迹视频里看不到。回车字头动画只能以本仓竖直杆层 + 支点 (1024, 1776) 参数为准，不得声称“与原版一致”。
- 设置页内部、色带切换实效、纸张切换实效、竖屏文档预览、XXX 删除实效，均未入镜。
- 拨杆换行动画未入镜（reel 与 TC 都没有拨杆特写）。

## 10. 版本差（2014 版已过时，仅作历史注记）

- 2026-11-03 用户定：2014 版演示过时，不再作为设计依据；本节只记历史，免得以后把旧版当新版用。
- 键盘配色：2014 版 Prime Select 浅色键，2025 版 reel 深色键——**以新版为准**。
- 机型数量：2014 版 3 台（Prime Select / 707 / Golden Touch），2017 年加 Del Sol / Electrix / Matterhorn，2025 版 reel 里 6 台全在 + 键盘扩展。
- 内购形态：老版单台 $2.99 / 打包 $4.99，2025 版 Bundle $9.99——价格只作历史注记，回车现阶段免费无内购，不对标。

## 11. 给回车的映射（只取动法与结构，不取外观与商业）

- 可取：顶栏（文档标题居中 + 汉堡菜单）与页码轨的布局关系；菜单“导航 + 格式化”两区结构；商店卡片“徽标 + 标语 + 照片 + 试用/收藏双钮 + 功能清单”的信息层级；标题页与正文页并排；分享走系统面板。
- 一切对标以 2025 版 reel 为准；2014 版内容不进入实现依据。
- 不取：内购按钮、Restore、$9.99 Bundle、Tom Hanks 签名营销、机型名与标语、键盘配色照搬——回车成就解锁免费、竖屏锁定、折叠三态是自有设计，不跟原版走。
- 回车独有、原版没有：折叠屏半开桌台模式、中文双通道输入、竖屏默认锁定——这三处没有原版对标，验收只按本仓文档。
