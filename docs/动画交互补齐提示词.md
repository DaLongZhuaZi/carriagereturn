# 回车：动画与交互补齐提示词

> 背景：桌面端已出第一版真机 build（包名 com.dlzz.carriagereturn），现状是毛坯：机器照片、纸面、键盘骨架都有，声音通了，但除声音外没有任何动画与交互。本提示词只补动画与交互，不改产品定义、不改机器外观、不改包名与应用名。

## 补齐清单（逐项实现、逐项录屏验）

1. **按键下沉与回弹**：自绘键盘用容器级 onTouch（不用 onClick），Map<触点 id, 键> 维护多点状态；TouchType.Down 当刻键缩放约 0.92（springCurve(0,1,200,18)），松开 springMotion() 回弹；动画只动 transform/透明度，不改布局。同一 Down 回调内顺序：动画 → 播音 → 震动（fire-and-forget），三者不得拆到不同回调。
2. **字头击打**：每次落字时竖直杆层绕支点 (1024, 1776) 从收起态摆到竖直击打态再回落；击打行程快、回程稍慢；字母出现在纸面的时刻必须与杆到位同帧，不得出现“键按了字先出、杆后到”或“杆动了字不出”。
3. **落字与光标**：字母按击打节奏逐字落纸（中文提交串拆单字 30–50ms 间隔）；光标前进一格，只光标前进、纸面不整体抖动；光标闪烁；预编辑串只显示（浅色 + 下划线），不发音、不落墨、不进文档模型。
4. **行 creep 与换行**：行满后纸面平滑上移一行（creep），不得跳变；距右边界约 8 字响行末预告铃（声 + 纸面轻提示）；回车键触发拨杆摆动动画 + 叮声 + 纸面上移 + 字车回位，四者同步。
5. **删除两种模式**：现代删除（字直接消失）与 XXX 覆盖（错字上打 X），两种都要有对应动画，删除键本身同样走第 1 条的下沉回弹。
6. **震动**：按键震动 15–30ms、usage 'touch'，权限 ohos.permission.VIBRATE 已在 entry 声明；震动缺失按 bug 计。
7. **换装过渡**：换纸张 / 色带 / 字体时，纸面与键盘配色淡入淡出过渡（约 200ms 级），不得闪白、不得整页重建导致光标与文档位置丢失。
8. **折叠屏三态不回归**：半开桌台模式下上述动画全部可用，切换布局时文档、光标、纸张位置全保留，不得 detach / re-attach 输入法。
