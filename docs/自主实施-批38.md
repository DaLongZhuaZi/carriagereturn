## 任务 1：盖面给"材料感"——径向光泽＋倒角线＋软阴影（binding，主项）

三样都要有，缺一样都算没做完。不要只做一样就报完成。

### 1a. 径向光泽（取代线性渐变）
- 盖面光泽由线性改**径向**：高光中心在盖面上部中央（约 x 181vp、y 180vp，
  即纸与字篮之间的盖面空白处），向四周柔和衰减；中心比 token 亮约 5%（L+0.05），
  四角比 token 暗约 4%（L−0.04），总量 ΔL ≤ 0.09。
- 之前批 37 的 2 停线性渐变（`shiftColor(token, ±10)`）删掉，不要留着叠加。
- 算过：盖面取样呈径向分布（中心亮、四角暗），不是上下线性；均值与 token 误差 ≤2。

### 1b. 边缘倒角线
- 盖面四周加一条 1–2px 的浅色倒角线（比 token 亮约 8%，L+0.08），沿盖面边缘走一圈，
  只在盖面与屏幕边缘／与黑色件（键盘井、字篮井口）交界处可见。
- 不要粗、不要亮到刺眼——是一条"厚度线"，不是装饰线。
- 算过：V=0 整机照（1805）里，盖面边缘有一圈极细的浅色线。

### 1c. 零件在盖面上的软阴影
- 纸、滚筒、字篮扇底座、键盘井——这四件压在盖面上的零件，各自在盖面上投一条**软阴影**：
  阴影为黑色、透明度 0.12–0.18、模糊半径 6–10px、向下方偏移 2–4px。
  阴影只出现在零件与盖面的交界处，不要满铺。
- 不要硬黑边、不要生硬的描边——是"软"阴影。
- 算过：纸下沿、滚筒下沿、扇底座下沿、键盘井上沿各有一条柔和的阴影带（1805 特写可见）。

### 1d. 不做什么
- 不要加木纹、颗粒、噪点、斑驳。盖面仍是光滑珐琅。
- 渐变总量仍 ≤0.09，均值与 token 误差仍 ≤2。

## 任务 2：字篮井去黑（binding，最大视觉改动）

- 井底由黑改成**与盖面同色薄荷绿**（四机各用各机的盖 token）。
  扇（银杆）直接长在机身上，同原版图 2。
- 井口曲线保留为一条**细的阴影线**（深色、1–2px、透明度约 0.5），不是一大片黑。
- 枢轴、扇底座保留，颜色不变。扇图仍用 `basket-fan-3d-v2.png`。
- 算过：字篮特写一张（1806），扇底为薄荷绿、扇杆银亮、井口曲线为细阴影线；
  整机照里字篮区不再有大黑半圆。

## 任务 3：顶栏去黑（binding）
