# 回车 CarriageReturn · 成就体系设计（行为绑定版）

> 状态：**已生效（2026-11-10 第 9 批 F5 落地）**。本文取代旧版"成就解锁新机器"口径。
> 事实源：`docs/designs/F5-成就行为绑定-增量设计.md`（v2.1，用户 2026-11-10 批准，按缺省执行）。
> 旧版本（2026-11-03 提案，机型绑定）**全文作废**，不留两份互相矛盾的设计。

## 1. 设计原则（用户 2026-11-10 铁律）

- **成就与使用行为绑定，不与特定机型绑定**：解锁条件是打字数、导出分享、换字体/色带等**行为**，不是"解锁某台机器"。
- **四台机永久全开**：2026-11-08 的"临时全解锁"转为永久状态，成就落地**不收回、不重锁**。`CollectionPage.unlocked()` 与 `CustomizePage.unlockedMachine()` 恒返回 true；收藏页的锁定态 UI（深色罩／锁图标／剪影 0.35）已随本批删除。
- **成就只奖行为本身**：成就是徽章＋进度，不开任何功能、不锁任何东西。
- **分享不设检查机制**：走常规导出分享即计，只按"分享面板已调起"计数；**绝不检查是否真发出、发到哪个平台**。
- **完全离线**：成就进度与计数只存本地（`@ohos.data.preferences`），零遥测、不上传。
- **成就名用时代／技术名，不用品牌名**；史实文字只放成就说明与图鉴，不进机器名、图标、商店截图。

## 3. 判定与触发（不变量）

- **判定只在保存／导出事件边界跑**，不走打字热路径；且在 `flushPending()`／`flushFoldTyped()` **完成之后**跑。
- `AchievementService.evaluate()` 的唯一调用点是 `Index.flushSave()`（保存／导出即 flush，每日至少一次），导出页的 `onSaved`／`onShared` 也各补一次。
- `consecutiveDays()` 与 `goalReached()` 都是**当日快照**（今天无落字＝0，跨日归零）；判定以达成当日的 flush 时刻为准，**一旦达成即写 prefs 永久保存**，次日归零不影响已达成态。
- 判定逻辑是纯函数 `model/AchievementCore.ets` 的 `evaluateAchieved(inputs)`；UI 只消费结果，不许再算一份。Node 单测覆盖（`tools/tests/achievement.test.mjs`）。
- 达成：写 `achieve.<id>`（只写一次，不重复提示）＋hilog `achieve <id> reached`（**不用"解锁"词汇**）。
- 多成就同时达成：AppDialog **一次只弹一个**，按成就表顺序排队；用户关掉一个再弹下一个，不叠弹窗。

## 4. 计数口径

- **字数**：按持久化累计落字计数器 `stats.total.chars` 计（落盘时累加，**只增不减**；删除／改短文档不扣减）。`totalWords()`（active 文档字数之和）只用于 F11／F14 显示，**不用于成就判定**。
- **连续天数**：按自然日（Asia/Hong_Kong）有落字（≥1 字）计一天，断一天重新累计。
- **分享**：按成功拉起系统分享面板计（取消也计）；与保存分开计——`onShared` 记 `doc_shared`，`onSaved` 记 `doc_exported`。
- **换装（字体／色带）**：用户主动切换即计（启动恢复不算）。
- **纸张**：`applyPaper` 成功并写入 `stats.paper.kinds` 集合即计；同一种纸重复换只计一次。
- **半开**：HALF_FOLDED 状态下有落字计（`fold_typed`）。
- **保存**：每次 `flushSave` 成功写盘计 1 次（不是不同文档数）。

## 5. 达成反馈

- 达成时弹 `AppDialog`（遮罩与卡片为 Stack 同层兄弟；点遮罩关、点卡片不关）。
- 弹窗内容：成就名＋一句话说明（文案走 `string.json`，不硬编码在渲染逻辑里）。
- 不与 HintBar／GuideOverlay 合并；不阻塞打字（只在保存／导出边界触发）；关掉即消失，不再重弹。
- 收藏页常驻成就列表：每项显示成就名、说明、进度（当前值／阈值）与已达成态；未达成只显示进度，不锁任何东西。
- F14 的"收藏进度"（总字数＋连续天数）收敛为成就列表顶部的进度区，不另留一行。

## 6. 迁移（上线首次评估）

- 上线时跑一次全量评估：
  - A4–A6 按评估当日的 flush 时刻判定；
  - A9–A10 依据已累计的 `stats.paper.kinds`；
  - A1–A3：累计落字计数器以评估时 `totalWords()` **一次性写入初值**——这是**近似值**（＝全部 active 文档字数之和），不是真实历史累计；此后只增不减；
  - A7–A8／A11–A14：事件计数器从触发点接线起才开始记，落地之前的使用**不补算**。
- 追认时只落盘、不弹一串弹窗：首次评估后**只弹一个汇总提示**（AppDialog"已达成 N 项成就"，附收藏页入口）；已落盘的成就不重复提示。
- 旧键清理：全仓零处调用 `PrefKeys.achieve()`，`achieve.machine_*` 从未写入，无清理项。

## 7. 不做的清单

不做付费解锁、排行榜、每日任务、限时活动（沿用旧设计 §6 不做清单，仍然有效）。
