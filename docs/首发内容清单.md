# 回车 CarriageReturn · 首发内容清单

> 状态：设计提案（2026-11-03）。依据：产品定义稿 v3.3、素材调研报告、音效调研报告、版权商标调研报告。
> **数量与款式均为提案，待用户点头**（定义稿 §8 第 2 项：首发机器数量与纸张数量未定）。
> 已定项（定义稿 v3.3）：美术 ＞ 功能；完全离线；现阶段免费无内购；收藏全部虚构时代机（Hanx 式做法）；中文字体首发走全量；导入首发范围为纸张加字体，音效包导入放二期。

## 1. 机器：4 台（提案，待用户点头）

| 机器（时代加结构命名） | 质感方向（提案） | 状态 |
|---|---|---|
| 1920s 直立式座机 | 黑色金属 | 默认机（提案） |
| 1950s 流线便携 | 米色、浅灰塑料 | 成就“流线时代”解锁（提案） |
| 1960s 电动式 | 浅灰、米白电动质感 | 成就“电动时代”解锁（提案） |
| 1930s 便携 | 深色皱纹漆 | 成就“便携时代”解锁（提案） |

- 来源与授权：机器身体为开发期 AI 生成原创渲染图（键帽文字一律代码矢量层，不 baked 进图）；每台机器先出 3/4 hero 图定稿，再衍生正面、侧面、键盘特写、纸面四视图。
- 渲染路线（提案，待用户点头，定义稿 §8 第 5 项）：Nano Banana 试用（Gemini 2.5 Flash Image 家族，现默认 Nano Banana 2；商用走付费 API，输出带不可见 SynthID 水印；商用前以 Google 官网条款原文为准）；Midjourney 付费版与 Flux schnell 自托管（Apache 2.0）作备选；Flux dev 系非商业许可禁用。
- 版权安全线：原创时代机，不用品牌名、Logo、1:1 标志性设计；AI 提示词禁用一切品牌名、型号名；生成后按标志性元素清单人工比对，撞脸即换方案；禁用组合清单（Valentine、Selectric、Lettera）见风格板设计稿 §8；参考照片（Wikimedia Commons 等）只看不取，不嵌入 App。
- 每台机器不只是皮肤：独立音效包、字体、键程手感与纸面适配（行距、边距）；解锁顺序打乱编年（见成就体系设计）。

## 2. 纸张：4 种（提案，待用户点头）

| 纸张 | 底纹来源与授权 | 备注 |
|---|---|---|
| 信纸 | CC0 底纹（Poly Haven、ambientCG）或程序化噪点；格线、边距代码画 | 默认纸（提案） |
| 稿纸 | 同上；红格、页眉代码画 | — |
| 明信片 | 底纹同上；图案走 AI 生成 | 图案授权同机器图 |
| 便签 | 底纹同上；图案走 AI 生成 | 图案授权同机器图 |

- Pexels、Pixabay 纹理禁原样再分发，不推荐（用户导出信纸图时纹理接近原样出包，CC0 可彻底避开灰区）。
- 首发纸张数量服从美术质量，宁少而精，不堆量（定义稿 v3.3）。

## 3. 色带：3 色（已定，定义稿 §5.3）

| 色带 | 用途 |
|---|---|
| 黑 | 默认墨色（提案） |
| 蓝 | 换色档 |
| 红 | 换色档 |

- 墨色影响落字颜色与纸面质感；句中可换色带（新落字用新墨色，旧字不变）；墨色以段为单位换 `fontColor`，做旧深浅以行为单位微调透明度。

## 4. 字体：4 款（提案，待用户点头）

| 字体 | 用途 | 授权 |
|---|---|---|
| Courier Prime | 英文默认打字机体 | SIL OFL 1.1；Regular/Bold/Italic/Bold Italic 齐全 |
| Special Elite | 英文做旧打字机体（墨色不均、磨损感） | SIL OFL 1.1（次级页面误标 Apache 以随包 OFL.txt 为准）；仅 Regular 一个字重、无粗斜体 |
| 中文宋体全量 | 中文默认宋体 | SIL OFL 1.1；Noto Serif SC 与思源宋体二选一（同源，提案，待用户点头） |
| LXGW WenKai 霞鹜文楷全量 | 中文楷体档（手写信感） | SIL OFL 1.1；保留字霞鹜/LXGW；作者明确可嵌入 App 捆绑销售 |

- 打包三条（已定）：附 OFL.txt、不单卖字体、改版守保留字（Plex、Source、霞鹜/LXGW）。
- 中文字体首发走全量已定（定义稿 v3.3）；全量 10–21MB/款，2 款中文全量加英文 2 款的包体代价需在打包时核算；子集化作包体超标时的 fallback。
- 字体注册走 `font.registerFont`（`$rawfile('font/xxx.ttf')`），支持 TTF/OTF；界面字体用系统默认字体（提案，见风格板设计稿 §3）。

## 5. 音效包：2 套（提案，待用户点头）

| 音效包 | 构成（来源与授权） | 用途 |
|---|---|---|
| 主包（Hermes） | BigSoundBank Hermes Precisa 305 三件套（全部 CC0，无需署名无需账号：打字床 s2838 切分 10–15 变体、空格单键 s2843、边际铃 s2844）加 Freesound CC0（ramsamba 318687 铃、knufds 345955 铃加回车一体、MasterNavigator 444813 纯铃） | 默认机与主用音色 |
| 第二台机包 | Freesound CC0：lyricalgirl 788956 打字床（带走廊回声，只作第二台机床料）加 BMacZero 160678 单键瞬态（0.116 秒，配床料做尾音） | 第二台机变体音色 |

- 第二梯队 CC BY（提案，待用户点头，见末尾清单）：ddohler 9098 单键、YleArkisto 271525（打字加铃加手动回车加卷纸一段）；采用即进设置→关于→音效致谢页（署名行用各文件页提供的署名文本生成）。
- 入库铁律（音效调研报告）：人工网站下载（Freesound API 免费档仅限非商业，禁用自动化拉取）；下载当刻记录协议快照加日期加哈希进 SOURCE.txt（上传者可改协议，快照即权利证据）；资源文件名去品牌化、品牌名只留 SOURCE.txt；403 未核实三处（ramsamba 318686、tams_kp 43558、OGA typewriter-sounds）不要重复请求，入库前人工浏览器复核；Tier 2 素材入库前逐页复核徽标。
- 红线：Mixkit、Pixabay、ZapSplat、99Sounds 只进编译产物，绝不以 loose 文件进公开 MIT 仓（禁 standalone 再分发；ZapSplat 另有“不得为项目主要价值”灰区，排最后）；BY-NC 与 Sampling+ 永不入库。
- 实录替换路线：实录为首选（采样清单见素材调研报告：按键 10–15 变体、空格 3–5、叮 2–3、回车杆整套、走纸、换档、退格，48kHz/24-bit，App 内总预算 <2MB）；实录到位后逐步替换占位包；实录真机来源待用户点头（定义稿 §8 第 6 项）。

## 6. 自定义导入首发范围（已定，定义稿 §5.3）

- 首发导入：纸张加字体。FilePicker 选文件后拷入沙箱并校验格式（图片 png/jpg/webp；字体 ttf/otf），字体走 `font.registerFont` 注册；导入内容只存本地，不上传；应用内提示“请确保你有权使用该字体”。
- 音效包导入放二期（已定）；首发不做音效包导入。
