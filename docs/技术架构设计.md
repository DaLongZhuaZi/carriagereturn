# 回车 CarriageReturn · 技术架构设计

> 状态：设计提案（2026-11-03）。依据：产品定义稿 v3.3、核心打字体验调研报告、素材调研报告、音效调研报告。
> 已定项（定义稿 v3.3）：包名 `com.dlzz.carriagereturn`；完全离线；现阶段免费无内购；收藏全部虚构时代机（Hanx 式做法）；文档只存本地；零遥测。
> 本稿中标注“提案，待用户点头”的事项均未定；未验证事项标注“待真机验证（定义稿 §8.1）”。
> 代码规范（仓库 AGENTS.md）：ArkTS 显式类型，禁 any/unknown；文案走资源文件，不硬编码在渲染逻辑里；默认不自动构建、打包、安装。

## 1. 模块划分

| 模块 | 职责 | 关键 API 与要点 |
|---|---|---|
| 自绘键盘 | 英文 QWERTY 机械键盘：键位布局、键程动画、多点触控、按键音触发 | 容器级 `onTouch` 加坐标到键位映射（不用 `onClick`）；`Map<触点id, 键>` 维护状态，Down 压下、Up/Cancel 回弹，抬起清理 id；`animateTo` 加弹簧曲线（按下 `springCurve(0, 1, 200, 18)`、缩放约 0.92，松开 `springMotion()`）；`keyframeAnimateTo` 不支持弹簧曲线，禁用；动画只动 transform 与透明度 |
| 纸面渲染 | 纸面主体、走纸、墨色、落字特效 | `List` 加 `LazyForEach` 加 `@Reusable`（`cachedCount` 约半屏）；光标行锚定，纸张随打字上移，当前行停在打字区高度；墨色以段换 `fontColor`、以行调透明度；Canvas 只做落字冲击、纸纹做旧的叠加特效；文档模型按行存数组 |
| 音频引擎 | 机器音包预加载、按键音、空格、叮声、回车杆、走纸、退格 | SoundPool（`@kit.AudioKit` `media.createSoundPool`）：启动时预加载整套机器音包；声音必须在 TouchType.Down 当刻触发；同 soundId 重播先停再播，快速连打用 2～3 个同类音色变体轮询加 `rate` 轻微随机防吃音；单音解码后不超过 1MB、时长 100ms 内；SoundPool 重叠行为待真机验证（定义稿 §8.1 第 4 项） |
| 震动 | 按键触感反馈（加分项） | `@ohos.vibrator`，15～30ms，`usage: 'touch'`；需声明 `ohos.permission.VIBRATE`；系统触感开关可能关掉震动，震动不能做唯一反馈；同一 Down 回调里依次触发动画、播音、震动（fire-and-forget） |
| 输入法接入 | 中文输入通道（推荐方案，提案，待用户点头） | IME Kit：`inputMethod.getController()`、`attach`、`showTextInput`/`hideTextInput`/`detach` 成对；`on('insertText'/'deleteLeft'/'deleteRight'/'moveCursor')`；`updateCursor`/`changeSelection` 同步光标；预编辑 `on('setPreviewText')`（API 17+，必须 attach 之前订阅，与 `finishTextPreview` 配对），预编辑层浅色加下划线、不发音不落墨；insertText 整词拆单字、以约 30～50ms 间隔逐字落字；第三方输入法 `setPreviewText` 兼容性与 `updateCursor` 坐标空间待真机验证（定义稿 §8.1 第 2、3 项） |
| 文档存储 | 文档保存、打开、重命名、删除；成就进度存储 | `@kit.CoreFileKit` `fileIo` 读写 `context.filesDir`（应用沙箱，无需权限）；文档存两份：JSON 与纯文本 .txt（见 §2）；成就进度与文档同属本地存储，不上传 |
| 导出 | 图片、PDF、纯文本导出 | 图片：`componentSnapshot.createFromBuilder` 离屏渲染（截图放在点击事件里，不放在构建期）；PixelMap 经 ImagePacker 打包后 `fs.write` 落沙箱；长图分段拼接并限制总高度（上限待真机验证，定义稿 §8.1 第 8 项）。PDF：A 路 PDF Kit 文本路径为主（`createDocument` → `insertBlankPage` → `getPage` → `addTextObject` 按行添加 → `addImageObject` 贴纸纹 → `saveDocument`；必须先 `insertBlankPage` 再 `getPage`），B 路 Webview createPdf 为兜底；PDF Kit 手机可用性与自定义字体嵌入待真机验证（定义稿 §8.1 第 1、6 项） |
| 系统分享 | 导出产物经系统分享发出 | Share Kit `systemShare`：uri 必须是 `fileUri.getUriFromPath(沙箱路径)` 转出的 file:// URI；缩略图限制 32KB 以下；PDF 的 UTD 串需实测确认，不硬编码猜测（待真机验证，定义稿 §8.1 第 7 项）；不做应用内广场、社交、评论 |
| 折叠屏适配 | 三态布局切换、折痕避让、角度节流 | `display.isFoldable()`、`getFoldStatus()`、`on('foldStatusChange')`、`on('foldAngleChange')`（API 12+）、`getCurrentFoldCreaseRegion()`；半开判定为 HALF_FOLDED 加横屏加角度约 60°～120°（社区实践值，Mate X 真机校准后定，待真机验证，定义稿 §8.1 第 5 项）；`foldStatusChange` 与 `foldDisplayModeChange` 时序不同，不混用；角度事件节流、防抖；折痕区取 `creaseRects[0]`（px）经 `uiContext.px2vp` 转 vp，上半屏高为折痕 top、下半屏为剩余减折痕高、折痕区留空；页面退出 `display.off` 防泄漏；非折叠大屏用 `windowSizeChange` 兜底 |
| 收藏 / 成就 | 机器图鉴、成就进度、解锁提示 | 成就体系见成就体系设计稿（全文为提案，待用户点头）；解锁提示文案走资源文件；未解锁机器显示锁定态与解锁条件，不提前展示完整机器图 |
| 设置 | 音量、震动、叮声、修正方式、默认纸张、默认机器；关于页；音效致谢页 | 零遥测说明常驻设置页；音效致谢页为提案，待用户点头（定义稿 §8 第 7 项），若采用 CC BY 素材则必需 |

## 2. 数据模型（建议，实施时定稿，待用户点头）

- 文档 JSON（建议字段）：文本行数组（`lines: string[]`，按行存，不存巨型字符串）加元数据：机器（`machine`）、纸张（`paper`）、色带（`ribbon`）、字体（`font`）、创建时间戳（`createdAt`）、更新时间戳（`updatedAt`）。字段名为建议，实施时定稿。
- 纯文本：同一文档另存一份 .txt（UTF-8，内容可再编辑）；JSON 与 .txt 成对保存、成对删除。
- 换装记录：换机、换纸、换色带、换字体均写入当前文档元数据；同一文档内换装不影响已有落字，已落字保留换装前的纸张、色带、字体呈现。
- 成就进度：本地存储（与文档同属应用沙箱），只记累计行为计数与解锁状态，不含任何用户身份信息。
- 自定义导入内容：只存本地（沙箱内导入目录），不上传；导入时校验格式（图片 png/jpg/webp；字体 ttf/otf），字体走 `font.registerFont` 注册。

## 3. 文件布局（建议，实施时定稿，待用户点头）

```
entry/src/main/resources/rawfile/
├── machine/        # 机器身体 AI 图（hero、正面、侧面、键盘特写、纸面四视图；键帽文字不进图，代码矢量层绘制）
├── paper/          # 纸面底纹（CC0 底纹或程序化噪点；格线、边距、红格、页眉代码画）
├── font/           # OFL 字体文件（每款附 OFL.txt；不单卖字体；改版守保留字）
├── sound/          # 音效包（主包 Hermes、第二台机包；每包附 SOURCE.txt：来源链接 + 下载时协议快照 + 文件哈希 + 切分记录）
└── （根）          # 资产授权清单（文件名、来源、协议、来源链接）随仓库走
```

- 应用沙箱文档目录：`context.filesDir`（`fileIo` 读写，无需权限）；用户可见位置用 FilePicker `DocumentSaveOptions` 或 `pickerMode: DOWNLOAD`（需用户授权，在 Download 下建以包名命名的文件夹）。
- 资源文件名去品牌化：品牌名只留在 SOURCE.txt 来源记录里，不进 App 内资源文件名或界面文案。
- Mixkit、Pixabay、ZapSplat、99Sounds 素材只进编译产物，绝不以 loose 文件进公开 MIT 仓（禁 standalone 再分发）；BY-NC 与 Sampling+ 永不入库。

## 4. 状态管理

- 文档模型、光标、纸张滚动位置放在 ViewModel / AppStorage，不放在随布局重建的页面局部 `@State`。
- 三态切换只换布局参数（纸高、键盘高、单双栏），不重建编辑器组件实例；键盘状态与文档状态分离，敲一键只刷新该键与当前行。
- 折叠切换时不 detach/re-attach 输入法（attach 只跟随焦点变化），否则中文输入会断。
- 中文输入双通道（自绘 QWERTY 英文加系统输入法 attach 中文）为调研推荐方案，提案，待用户点头（定义稿 §8 第 1 项）；自绘键盘加拼音候选行等于自建输入法，成本远超收益，首发不做。

## 5. 权限

| 权限 / 授权 | 用途 | 说明 |
|---|---|---|
| `ohos.permission.VIBRATE` | 按键震动 | 需声明；系统触感开关可能关掉震动，震动只能做加分项 |
| 应用沙箱 `context.filesDir` 读写 | 文档存储 | 无需权限 |
| FilePicker 用户可见位置 | 导出到用户选定位置、Download 文件夹 | 需用户授权（用户选保存位置即授权） |
| 自定义导入 | FilePicker 选文件拷入沙箱 | 需用户选文件即授权；导入内容只存本地 |

- 不申请网络权限、不设账号、不做云同步；全部功能本地完成，断网可用。

## 6. 零遥测、零联网

- 用户文档与按键数据只存本地，不收集、不上传、不做遥测；零遥测说明常驻设置页。
- App 内不跑模型、不做 AI 生成与 AI 写作；AI 只用于开发期图片、视频素材，上架产物是纯离线渲染、动画与音效。
- 不做应用内社交、广场、评论；不做 OCR、扫描；首发不做应用内打印机直连（导出后走系统打印即可）；首发不做音效包导入（二期）。
